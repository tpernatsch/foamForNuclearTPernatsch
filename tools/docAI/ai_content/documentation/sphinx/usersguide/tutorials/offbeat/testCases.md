# Test Cases and Tutorials

This folder contains a collection of **test cases and example problems** for the **OFFBEAT** code.

They are intended as practical examples that illustrate how to set up and run simulations.

> **Warning**
> OFFBEAT is currently undergoing significant refactoring due to:
>
> * the merger with **GeN-Foam** into the **foamForNuclear** framework, and
> * the introduction of a new Python API.
>
> As a result, legacy test cases that have not yet been migrated to the new format have been moved to the `deprecated/` folder.
>
> *Deprecated* here refers to **syntax and case structure**, not necessarily to the underlying physics models. **Many of these cases may still run as-is or require only minor adjustments**, since backward compatibility is preserved where possible. The separation is primarily meant to clarify which cases reflect the current recommended workflow.
