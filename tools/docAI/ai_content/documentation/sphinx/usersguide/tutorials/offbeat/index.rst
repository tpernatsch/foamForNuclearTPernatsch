Offbeat Tutorials
==================

This section collects “offbeat” tutorials that complement the main workflow by focusing on practical validation, robustness, and reproducibility in foamForNuclear simulations. The Verification subsection explains how to check that model outputs are consistent with expected behavior, while the restart subsection covers how to continue or recover runs without losing the integrity of the underlying physics setup. Finally, Test Cases and Tutorials provides concrete, end-to-end examples that tie verification and restart practices together, so graduate students can both test their configurations and rerun studies efficiently.
