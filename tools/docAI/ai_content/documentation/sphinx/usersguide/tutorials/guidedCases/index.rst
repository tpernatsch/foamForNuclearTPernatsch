Guided Cases Tutorials
======================

This section provides guided, end-to-end tutorial cases that demonstrate how to set up and run representative neutronics diffusion problems in foamForNuclear. It starts with a baseline “Neutronics Diffusion: Slab Reactor” case to establish the core modeling workflow, then extends the same slab configuration in “Neutronics Diffusion: Slab Reactor with a reflector” to show how adding a reflector changes the neutron field and boundary effects. Finally, “ESFR Workshop” shifts to a more application-oriented benchmark-style setup, helping you connect the earlier diffusion concepts to a workshop case context.
