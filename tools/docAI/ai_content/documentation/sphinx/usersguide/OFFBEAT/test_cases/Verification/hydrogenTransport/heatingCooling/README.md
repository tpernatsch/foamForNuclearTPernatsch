# Heating and Cooling Test Case

A Zircaloy sample is precharged with 200 wt.ppm. of hydrogen. It is then repeatedly cooled from 650 K to 300 K at different cooling rates. The TSSp and TSSd curves from BISON are used. The hydrogen behaviour is summarised in the figure below. The results agree well with the reference provided by Passelaigue et al.[^1].
