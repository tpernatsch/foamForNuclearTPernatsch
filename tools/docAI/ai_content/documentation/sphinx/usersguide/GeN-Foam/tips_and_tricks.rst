Tips and tricks
===============

- The easiest way to build a new case in GeN-Foam is often to start from a tutorial that closely resembles the case of interest.
- If you are unsure about the functionality of a class, consult the corresponding C++ documentation.
- If you are unsure about the meaning of an input parameter, consult the tutorials. Many of them are commented. Another option is the famous "banana method". Type in anything (for example, "banana"). In many cases, the solver will tell you that "banana" is not a valid option and will suggest valid options.
