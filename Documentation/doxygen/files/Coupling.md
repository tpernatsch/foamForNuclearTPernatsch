
# Coupling options and time stepping {#COUPLING}

**Work in progress!!**

## Introduction

GeN-Foam can selectively couple each physics. The selection of the physics to solve is done in *system/controlDict* while the parameters for the coupling are set in *system/fvSolution*.

The *controlDict* is extended compared to a standard OpenFOAM controlDict in order to control what solvers are activated and flags that affect the behaviour of GeN-Foam as a whole.
