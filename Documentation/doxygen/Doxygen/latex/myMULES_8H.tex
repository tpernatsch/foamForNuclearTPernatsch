\subsection{Detailed Description}
my\+M\+U\+L\+ES\+: Multidimensional universal limiter for explicit solution. 

{\bfseries Original source file} \href{../../../home/carlo/data/GeN-Foam/GeN-Foam_ffn/GeN-Foam/GeN-Foam/classes/thermalHydraulics/solvers/twoPhase/include/alphaEqnsRoutines/myMULES/myMULES.H}{\tt my\+M\+U\+L\+E\+S.\+H}

\label{_Description}%
 Solve a convective-\/only transport equation using an explicit universal multi-\/dimensional limiter.

Parameters are the variable to solve, the normal convective flux and the actual explicit flux of the variable which is also used to return limited flux used in the bounded-\/solution. This version is virtually indentical to the M\+U\+L\+ES present in Open\+F\+O\+A\+M6. The main difference consists in the option to provide a space-\/dependent limiter field, something which is absent in the v1812 Open\+F\+O\+AM version of M\+U\+L\+ES.
