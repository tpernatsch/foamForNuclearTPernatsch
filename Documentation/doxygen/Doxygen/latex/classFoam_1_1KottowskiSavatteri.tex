\subsection{Detailed Description}
Model by Kottowski and Savatteri for the multiplier, specifically for sodium two-\/phase flows\+: 

\label{_Description}%
 phi2 = 10$^\wedge$(2$\ast$( 0.\+1046$\ast$(log10X)$^\wedge$2 -\/ 0.\+5098$\ast$log10X + 0.\+6252 ))

log10 is the log in basis 10, while X2 is the well-\/known Lockhart-\/\+Martinelli parameter and is defined as\+:

X2 = (mu\+\_\+\+I/mu\+\_\+O)$^\wedge$0.2 $\ast$ (flow\+Quality\+\_\+\+I/flow\+Quality\+\_\+O)$^\wedge$1.8 $\ast$ rho\+\_\+\+O/rho\+\_\+I

Please note that X in use in phi2 is X = sqrt(\+X2). The correlation for phi2 was derived in the data range 7e-\/2 $<$ X $<$ 30.
