\hypertarget{classFoam_1_1XSLowMem}{}\section{X\+S\+Low\+Mem Class Reference}
\label{classFoam_1_1XSLowMem}\index{X\+S\+Low\+Mem@{X\+S\+Low\+Mem}}


Class for \hyperlink{classFoam_1_1XS}{XS} parametrization. Used in \hyperlink{classFoam_1_1SNNeutronics}{S\+N\+Neutronics}. Low memory version of \hyperlink{classFoam_1_1XS}{XS}. Essentially it does not store the full scattering matrix, but it parametrize and return each component on request. One additional feature is that it creates (and can return) a sigma\+From\+To\+Yes\+No matrix that is filled with zeros and ones. One in position (i,j) implies that there is an exchange of neutrons from group i to j somewhere in the geometry. It can be used to speed up the calculations of scattering sources.

\subsection{Detailed Description}
Class for \hyperlink{classFoam_1_1XS}{XS} parametrization. Used in \hyperlink{classFoam_1_1SNNeutronics}{S\+N\+Neutronics}. Low memory version of \hyperlink{classFoam_1_1XS}{XS}. Essentially it does not store the full scattering matrix, but it parametrize and return each component on request. One additional feature is that it creates (and can return) a sigma\+From\+To\+Yes\+No matrix that is filled with zeros and ones. One in position (i,j) implies that there is an exchange of neutrons from group i to j somewhere in the geometry. It can be used to speed up the calculations of scattering sources.
