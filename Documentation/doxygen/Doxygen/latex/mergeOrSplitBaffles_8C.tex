\subsection{Detailed Description}
Detects boundary faces that share points (baffles). Either merges them or duplicate the points. 

{\bfseries Original source file} \href{../../../home/carlo/data/GeN-Foam/GeN-Foam_ffn/GeN-Foam/GeN-Foam/include/mergeOrSplitBaffles.C}{\tt merge\+Or\+Split\+Baffles.\+C}

\label{_Description}%
 \begin{DoxyParagraph}{Usage}
{\bfseries merge\+Or\+Split\+Baffles} \mbox{[}O\+P\+T\+I\+ON\mbox{]}
\end{DoxyParagraph}
Options\+:
\begin{DoxyItemize}
\item \begin{DoxyParagraph}{-\/detect\+Only}
Detect baffles and write to face\+Set duplicate\+Faces.
\end{DoxyParagraph}

\item \begin{DoxyParagraph}{-\/split}
Detect baffles and duplicate the points (used so the two sides can move independently)
\end{DoxyParagraph}

\item \begin{DoxyParagraph}{-\/dict $<$dictionary$>$}
Specify a dictionary to read actions from.
\end{DoxyParagraph}
\begin{DoxyNote}{Note}

\end{DoxyNote}

\end{DoxyItemize}

can only handle pairwise boundary faces. So three faces using the same points is not handled (is illegal mesh anyway)


\begin{DoxyItemize}
\item surfaces consisting of duplicate faces can be topologically split if the points on the interior of the surface cannot walk to all the cells that use them in one go.
\item Parallel operation (where duplicate face is perpendicular to a coupled boundary) is supported but not really tested. (Note that coupled faces themselves are not seen as duplicate faces) 
\end{DoxyItemize}
