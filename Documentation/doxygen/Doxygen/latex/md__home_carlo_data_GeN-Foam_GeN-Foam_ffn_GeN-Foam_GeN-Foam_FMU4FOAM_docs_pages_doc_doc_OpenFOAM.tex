\subsection*{Open\+F\+O\+AM}

Open\+F\+O\+AM is a C++ library for solving P\+D\+Es with the special focus on Computional Fluid Dynamics with a large user base in academia and industry. Incompressible, compressible, reacting and multiphase flow with numerous models can be simulated. These different flow types are all addressed by multiple \href{https://www.openfoam.com/documentation/user-guide/a-reference/a.1-standard-solvers}{\tt applications} that all have a unique set of input parameters. An Open\+Foam case consists of three main folders\+: \char`\"{}system\char`\"{}, \char`\"{}constant\char`\"{} and \char`\"{}time directories\char`\"{} as described in the \href{https://www.openfoam.com/documentation/user-guide/2-openfoam-cases/2.1-file-structure-of-openfoam-cases}{\tt Open\+F\+O\+AM user guide}. The \char`\"{}system\char`\"{} folder mainly contains the numerical parameters of a simulation, the \char`\"{}constant\char`\"{} folder the physical model such as the fluid properties or the selected turbulence model and the \char`\"{}time folder\char`\"{} stores the computed fields.
