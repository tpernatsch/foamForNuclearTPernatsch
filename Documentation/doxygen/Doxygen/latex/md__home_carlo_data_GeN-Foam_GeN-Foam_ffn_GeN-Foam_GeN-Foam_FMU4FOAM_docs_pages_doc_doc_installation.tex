\subsection*{Prerequisite}

The library requires Open\+F\+O\+AM version v2012 or higher. Open\+F\+O\+AM can be build from https\+://develop.openfoam.\+com/\+Development/openfoam/-\//blob/master/doc/\+Build.md \char`\"{}source\char`\"{} or installed with the \href{https://develop.openfoam.com/Development/openfoam/-/wikis/precompiled}{\tt package manager}. The installation also requires the installation of python on the system that can easily be installed with the \href{https://www.anaconda.com/products/individual}{\tt anaconda}

\subsubsection*{Linux}


\begin{DoxyCode}
curl -s https://dl.openfoam.com/add-debian-repo.sh | sudo bash
wget -q -O - https://dl.openfoam.com/add-debian-repo.sh | sudo bash
sudo apt-get install openfoam2106-default # change to openfoam2012-default for v2012
\end{DoxyCode}


\subsubsection*{W\+SL}


\begin{DoxyCode}
sudo apt-get update
sudo apt-get install -y dos2unix ca-certificates cmake
sudo find . -type f -exec dos2unix \{\} \(\backslash\); # required cloned on a windows machine
curl -s https://dl.openfoam.com/add-debian-repo.sh | sudo bash
wget -q -O - https://dl.openfoam.com/add-debian-repo.sh | sudo bash
sudo apt-get install -y openfoam2106-default # change to openfoam2012-default for v2012
sudo apt-get install -y libatlas-base-dev
\end{DoxyCode}


After the installation on W\+SL or Liunx, the Open\+F\+O\+AM enviroment needs to be set with


\begin{DoxyCode}
source <installation path>/OpenFOAM-v2106/etc/bashrc
\end{DoxyCode}


In order to avoid sourcing the enviroment with every new terminal session, the above line can be added with a text editor at the bottom of the .bashrc


\begin{DoxyCode}
alias of2106='source <installation path>/OpenFOAM-v2106/etc/bashrc'
alias of2012='source <installation path>/OpenFOAM-v2012/etc/bashrc'
\end{DoxyCode}


Another option is to define an alias in the bashrc. This way, multiple Open\+F\+O\+AM version can be installed and switched easily by typing of2106 or of2012 in the terminal

\begin{DoxyCode}

\end{DoxyCode}


Install the F\+MU build tool


\begin{DoxyCode}

\end{DoxyCode}
