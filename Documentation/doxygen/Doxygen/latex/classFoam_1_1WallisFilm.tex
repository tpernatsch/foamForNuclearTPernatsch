\subsection{Detailed Description}
Correlation to be used in annular flow scenarios in which the phase of interest to which this model is applied flows in a film along the structures (e.\+g. pins) of interest. It assumes that the dimensionless film thickness d+ (=d/\+Dh with Dh being the structure hydraulic diameter) is proportional to the Wallis interfacial drag coefficient so that\+: 

\label{_Description}%
 0.\+005$\ast$75$\ast$alphaN = 0.\+005$\ast$300$\ast$d/\+Dh

with alphaN being the normalized phase fraction of the phase of interest and the film thickness is thus computed as\+:

d = 0.\+25$\ast$alpha\+N$\ast$\+Dh
