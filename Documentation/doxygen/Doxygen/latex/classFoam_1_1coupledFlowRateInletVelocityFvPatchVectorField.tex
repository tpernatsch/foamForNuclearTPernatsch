\subsection{Detailed Description}
Velocity inlet boundary condition either correcting the extrapolated velocity or creating a uniform velocity field normal to the patch adjusted to match the specified flow rate. 

\label{_Description}%
 For a mass-\/based flux\+:
\begin{DoxyItemize}
\item the flow rate should be provided in kg/s
\item if {\ttfamily rho} is \char`\"{}none\char`\"{} the flow rate is in m3/s
\item otherwise {\ttfamily rho} should correspond to the name of the density field
\item if the density field cannot be found in the database, the user must specify the inlet density using the {\ttfamily rho\+Inlet} entry
\end{DoxyItemize}

For a volumetric-\/based flux\+:
\begin{DoxyItemize}
\item the flow rate is in m3/s
\end{DoxyItemize}

\begin{DoxyNote}{Note}

\begin{DoxyItemize}
\item {\ttfamily rho\+Inlet} is required for the case of a mass flow rate, where the density field is not available at start-\/up
\item The value is positive into the domain (as an inlet)
\item May not work correctly for transonic inlets
\item Strange behaviour with potential\+Foam since the U equation is not solved
\end{DoxyItemize}
