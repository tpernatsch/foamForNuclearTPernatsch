Model by Kaiser et al. for the multiplier, specifically for sodium two-\/phase flows\+: 

\label{_Description}%
 phi2 = exp(2$\ast$( 1.\+48 -\/ 1.\+05$\ast$log(sqrt(\+X)) + 0.\+09$\ast$(log(sqrt(\+X)))$^\wedge$2 ))

log is the natural logarithm and X2 is the well-\/known Lockhart-\/\+Martinelli parameter defined as\+:

X2 = (mu\+\_\+\+I/mu\+\_\+O)$^\wedge$0.2 $\ast$ (flow\+Quality\+\_\+\+I/flow\+Quality\+\_\+O)$^\wedge$1.8 $\ast$ rho\+\_\+\+O/rho\+\_\+I

Please note that X in use in phi2 is X = sqrt(\+X2).
