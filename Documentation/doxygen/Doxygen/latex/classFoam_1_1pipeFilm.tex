\subsection{Detailed Description}
Correlation to be used in annular flow scenarios in which the phase of interest to which this model is applied flows in a film along the walls of a circular pipe, so that the film thickness is proportional to 1-\/sqrt(1-\/alphaN) with alphaN being the normalized phase fraction of the phase of interest.
