Simplifies the linking process of external libraries to Open\+F\+O\+AM

New libraries can be download easily from the conancenter and linked to Open\+F\+O\+AM

\section*{Prerequisite}

Assuming we already have anaconda and Open\+F\+O\+AM is sourced installed\+:


\begin{DoxyCode}
conda create -n conan python=3.9 # we dont want break our install
conda activate conan
pip install conan # conan is required
\end{DoxyCode}


\section*{Usage}

cat option.\+template\+: 
\begin{DoxyCode}
CONAN\_INCS := \(\backslash\)
    \{\{\{CONAN\_INCS\_INCS\}\}\}

CONAN\_LIBS := \(\backslash\)
    \{\{\{CONAN\_INCS\_LIBS\}\}\}


EXE\_INC = \(\backslash\)
    -I../../../src/lnInclude \(\backslash\)
    -I$(LIB\_SRC)/finiteVolume/lnInclude \(\backslash\)
    -I$(LIB\_SRC)/meshTools/lnInclude \(\backslash\)
    $(CONAN\_INCS)

EXE\_LIBS = \(\backslash\)
    -lfiniteVolume \(\backslash\)
    -lmeshTools \(\backslash\)
    $(CONAN\_LIBS)
\end{DoxyCode}


add C\+O\+N\+A\+N\+\_\+\+I\+N\+CS and C\+O\+N\+A\+N\+\_\+\+L\+I\+BS to your options file and place it in the Make folder. The generator will replace

\{\{\{C\+O\+N\+A\+N\+\_\+\+I\+N\+C\+S\+\_\+\+I\+N\+CS\}\}\}

and

\{\{\{C\+O\+N\+A\+N\+\_\+\+I\+N\+C\+S\+\_\+\+L\+I\+BS\}\}\}

with the cached libraries in conan

\subsection*{Install Open\+F\+O\+AM generator}


\begin{DoxyCode}
cd OpenFOAMGen
conan export . myuser/OpenFOAMGen
\end{DoxyCode}


The generator is now installed

\subsection*{Compile Open\+F\+O\+AM with Boost regexp and lohmann json}


\begin{DoxyCode}
cd test-conan
conan install . -s compiler=gcc -s compiler.libcxx=libstdc++11 --build
\end{DoxyCode}


boost and the json library are now downloaded and compiled. Conan needs to know the compiler version and the c++ standard to download the correct version.

Note\+: this will take a while.
