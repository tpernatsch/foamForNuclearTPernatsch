\subsection{Detailed Description}
Interrogate and manipulate dictionaries. 

{\bfseries Original source file} \href{../../../home/carlo/data/GeN-Foam/GeN-Foam_ffn/GeN-Foam/GeN-Foam/FMU4FOAM/application/tools/dictModifier/dictModifier.C}{\tt dict\+Modifier.\+C}

\label{_Description}%
 \begin{DoxyParagraph}{Usage}
{\bfseries foam\+Dictionary} \mbox{[}O\+P\+T\+I\+ON\mbox{]} dictionary
\end{DoxyParagraph}

\begin{DoxyItemize}
\item \begin{DoxyParagraph}{-\/entry $<$name$>$}
Selects an entry
\end{DoxyParagraph}

\item \begin{DoxyParagraph}{-\/keywords}
Prints the keywords (of the selected entry or of the top level if no entry was selected
\end{DoxyParagraph}

\item \begin{DoxyParagraph}{-\/add $<$value$>$}
Adds the entry (should not exist yet)
\end{DoxyParagraph}

\item \begin{DoxyParagraph}{-\/set $<$value$>$}
Adds or replaces the entry
\end{DoxyParagraph}

\item \begin{DoxyParagraph}{-\/remove}
Remove the selected entry
\end{DoxyParagraph}

\item \begin{DoxyParagraph}{-\/diff $<$dictionary$>$}
Write differences with respect to the specified dictionary (or sub entry if -\/entry specified)
\end{DoxyParagraph}

\item \begin{DoxyParagraph}{-\/diff-\/etc $<$dictionary$>$}
Write differences with respect to the specified dictionary (or sub entry if -\/entry specified)
\end{DoxyParagraph}

\item \begin{DoxyParagraph}{-\/expand}
Read the specified dictionary file, expand the macros etc. and write the resulting dictionary to standard output.
\end{DoxyParagraph}

\item \begin{DoxyParagraph}{-\/includes}
List the {\ttfamily \#include} and {\ttfamily \#sinclude} files to standard output
\end{DoxyParagraph}

\item \begin{DoxyParagraph}{-\/disable\+Function\+Entries}
Do not expand macros or directives (\#include etc)
\end{DoxyParagraph}

\item \begin{DoxyParagraph}{-\/precision int}
Set default write precision for I\+Ostreams
\end{DoxyParagraph}
Example usage\+:
\item Change simulation to run for one timestep only\+: \begin{DoxyVerb}      foamDictionary system/controlDict -entry stopAt -set writeNow\end{DoxyVerb}

\item Change solver\+: \begin{DoxyVerb}       foamDictionary system/fvSolution -entry solvers.p.solver -set PCG\end{DoxyVerb}

\item Print bc type\+: \begin{DoxyVerb}       foamDictionary 0/U -entry boundaryField.movingWall.type\end{DoxyVerb}

\item Change bc parameter\+: \begin{DoxyVerb}       foamDictionary 0/U -entry boundaryField.movingWall.value \
         -set "uniform (2 0 0)"\end{DoxyVerb}

\item Change whole bc type\+: \begin{DoxyVerb}      foamDictionary 0/U -entry boundaryField.movingWall \
        -set "{type uniformFixedValue; uniformValue (2 0 0);}"\end{DoxyVerb}

\item Write the differences with respect to a template dictionary\+: \begin{DoxyVerb}      foamDictionary 0/U -diff-etc templates/closedVolume/0/U\end{DoxyVerb}

\item Write the differences in boundary\+Field with respect to a template dictionary\+: \begin{DoxyVerb}      foamDictionary 0/U -diff-etc templates/closedVolume/0/U \
        -entry boundaryField\end{DoxyVerb}

\item Change patch type\+: \begin{DoxyVerb}      foamDictionary constant/polyMesh/boundary \
        -entry entry0.fixedWalls.type -set patch\end{DoxyVerb}
 This uses special parsing of Lists which stores these in the dictionary with keyword \textquotesingle{}entry\+D\+DD\textquotesingle{} where D\+DD is the position in the dictionary (after ignoring the Foam\+File entry).
\end{DoxyItemize}

Notes\+:
\begin{DoxyItemize}
\item the use of \textquotesingle{}.\textquotesingle{} as the scoping symbol might conflict with e.\+g. file extensions (\textquotesingle{}.\textquotesingle{} is not really considered to be a valid word character). Instead use the \textquotesingle{}/\textquotesingle{} as a scoping character e.\+g. foam\+Dictionary system/snappy\+Hex\+Mesh\+Dict \textbackslash{} -\/entry /geometry/motor\+Bike.obj -\/remove 
\end{DoxyItemize}
