## Instructions

- Use `./Allrun` from the top directory

- This runs a thermal-hydraulic simulation using the Albedo BC-generated power distribution

## Introduction

This repository contains the transient coupled thermal-hydraulic/neutronic solution of a particle bed reactor (PBR) core, with power densities obtained using Serpent. This core was designed for use in a Nuclear Thermal Propulsion (NTP) system. The PBR design is based on the paper by (Ludewig, 1993).
