Detailed Description

Burst overstress criterion for Zircaloy-4 derived from BISON code. NOTE: oxidation contribution still needs to be included.

Usage
In solverDict file: 
materials
{
    cladding
    {
        failureModel    ZyOverstressBISON;
        stopIfFailed    on;
        failureModelOptions
        {
            patchNames      ( "cladOuter" "cladInner" );
        }
    }
}
