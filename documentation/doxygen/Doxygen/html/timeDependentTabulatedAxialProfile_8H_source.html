24 Class
25  Foam::timeDependentTabulatedAxialProfile
26 
27 Description
28  Class providing a time-dependent axial profile, which is defined by the
29  user by interpolation in a 2D lookup table as a function of axial
30  location and time, i.e. f(z,t).
31  Both "step" and "linear" interpolation methods are supported (see
32  Foam::InterpolateTable).
33  The supplied profile must be normalised to 1.
34 
35  The class is provided with a mesh and addressing array, and then deals with
36  the mapping of the profile onto an addressed list, which can be accessed
37  through the profile function.
38 
39 Usage
40  \verbatim
41  {
42  type timeDependentTabulated;
43  timePoints ( 0 100 );
44  axialLocations ( 0.0 0.5 1.0 );
45  data ( ( 0.5 1.0 1.5 )
46  ( 0.8 1.1 1.0 ) );
47  axialInterpolationMethod linear;
48  timeInterpolationMethod linear;
49 
50  }
51  \endverbatim
