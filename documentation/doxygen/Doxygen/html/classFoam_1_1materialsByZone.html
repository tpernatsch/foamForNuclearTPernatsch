Detailed Description

The materials are identified with the cellZones. However, the same material model (e.g. UO2, MOX, zircaloy etc) can be used in different cellZones.

The material properties are provided in a subDictionary called "materials". The class will check that all cellZones are assigned with one (and only one) material model.

Usage
In solverDict file: 
materialProperties byZone;

// List of materials, one per cellZone.
materials
{
    fuel
    {
        material UO2;
        ...
    }

    cladding
    {
        material zircaloy;
        ...
    }
}
