24 Class
25  Foam::radialProfile
26 
27 Description
28  Base class for a general profile in the radial direction. The base
29  class assumes a uniform "flat" profile.
30  The class is provided with a mesh and addressing array, and then deals with
31  the mapping of the profile onto an addressed list, which can be accessed
32  through the profile function.
