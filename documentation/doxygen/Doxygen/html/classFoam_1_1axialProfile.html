Detailed Description

Base class for a general profile in the axial direction. The base class assumes a uniform "flat" profile. The class is provided with a mesh and addressing array, and then deals with the mapping of the profile onto an addressed list, which can be accessed through the profile function.

Usage
{
    type    "flat";
}
