Detailed Description

Saturation model for water in the 0.01-350 C range based on an interpolation of NIST data in the form Psat = A(T-B)^C. The NIST data can be found at: https://www.nist.gov/system/files/documents/srd/NISTIR5078-Tab1.pdf.
