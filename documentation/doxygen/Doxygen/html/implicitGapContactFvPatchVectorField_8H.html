Class Foam::implicitGapContactFvPatchVectorField

Description Frictional contact boundary condition, similar to implicit contact.

The normal contact component of the stress is discretized implicitly. A blending coefficient is used to transition smoothly between the two conditions of open and closed gap.

The tangent traction is always treated explicitly (as in a fixed gradient BC). However the details of the implementation change when moving from open gap conditiosn (zero tangent traction) to full contact. In particular, in the latter condition, the tangent component of the gradient is added implicitly (see gradientBoundaryCoeff and gradientInternalCoeff functions), and subtracted explicitly (see explicitTraction in the source code). This helps convergence.

The user can select the amount of friction allowed with the frictionCoefficient. If large enough, the material will tend to bond when in contact. However, note that the full bonding traction is applied only when the blending coefficient approaches 1 (and the frictionCoefficient is infinite).

If glued is set to true, the material are assumed to be bonded (blending coefficient is 1).

Usage 

    "fuelOuter|claddingInner"
    {
        type            implicitGapContact;
        patchType       regionCoupledOFFBEAT;
        
        // "off" by default. If "on" th patches are assumed
        // to be glued to each other
        glued off;

        // A new method of handling contact force can be activated using the 'augmentedLagrangian' method. 
        // By default, the method is set to 'implicitPenalty'. 
        // When using 'augmentedLagrangian', you can also set the relativePenetration tolerance. 
        // This tolerance defines the fraction of cell depth (delta) at which the penetration is considered acceptable.

        // method augmentedLagrangian;
        // relativePenetrationTolerance 0.001;

        // Similar to penalty factor in explicit BC, the higher
        // it is the more accurate the contact overlap, but more
        // complex the convergence
        penaltyFactor           0.1;
        penaltyFactorFriction   0.001;
        penaltyFactorDashpot      0.0;

        frictionCoefficient        0;
        
        relax 0.1;
        
        traction        uniform (0 0 0);
        pressure        uniform 2.25e6;
        value           $internalField;
    }
