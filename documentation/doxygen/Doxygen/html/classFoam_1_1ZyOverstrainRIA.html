Detailed Description

Overstrain criterion to asses clad failure during the PCMI phase of a RIA transient.

If the hoop strain is superior to a critical value, the clad is considered failed. Critical value of hoop strain is a function of Temperature, strain rate, hydrogen content and fast neutron fluence (E > 1 MeV)

From: https://inis.iaea.org/collection/NCLCollectionStore/_Public/42/022/42022542.pdf

Usage
In solverDict file: 
materials
{
    cladding
    {
        material zircaloy;

        ...

        failureModel         ZyOverstrainRIA;
        CH       400;
        phi       1; //Fast neutron fluence in 1e25 n/m2
        stopIfFailed         false;
    }

    ...
}
