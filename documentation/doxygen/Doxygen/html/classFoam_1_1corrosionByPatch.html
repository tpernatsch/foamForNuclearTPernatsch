Detailed Description

A corrosion model is created for each patch listed in the corrosionOptions dictionary.

A polyTopoChanger is created with layerAdditionRemoval polyMeshModifiers for each patch is created.

At each iteration:

  • the patch corrosion models are corrected
  • the patch face points are moved with the metal thickness change
  • if it is the first iteration of the current time step, the polyTopoChanger checks whether the topology should be updated by removing or adding a cell layer.

Usage
In solverDict file: 
burnup byPatch;

corrosionOptions
{
    // The updateMesh switch is set to true by default
    updateMesh     true;

    // The subdictionary must contain at least one patch
    patches
    {
        cladOuter  zircaloyOuterCorrosion;// fromLatestTime;
    }
}
