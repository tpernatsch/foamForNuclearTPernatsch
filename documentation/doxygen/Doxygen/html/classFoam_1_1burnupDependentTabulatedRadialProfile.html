Detailed Description

Class providing a burnup-dependent radial profile, which is defined by the user by interpolation in a 2D lookup table as a function of radial location and burnup, i.e. g(Bu,r). Both "step" and "linear" interpolation methods are supported (see Foam::InterpolateTable). The supplied radial profiles must be normalised to 1, taking note that the integral will be in cylindrical coordinates. The fuel average burnup is assumed, i.e. no axial effects are included.

The class is provided with a mesh and addressing array, and then deals with the mapping of the profile onto an addressed list, which can be accessed through the profile function.

Usage
{
    type            burnupDependentTabulated;
    burnupPoints    ( 0 70e3 );
    radialLocations ( 0 0.4472135955 0.632455532 0.7745966692 0.894427191 1 );
    data            ( 
        ( 0.8319626974 0.90037028 0.9485969551 1.006237685 1.090645345 1.276336774 )
        ( 0.7179025511 0.8243673183 0.9031851172 1.001405018 1.153001744 1.518179055 )
    );
    radialInterpolationMethod    linear;
    burnupInterpolationMethod    linear;
}
