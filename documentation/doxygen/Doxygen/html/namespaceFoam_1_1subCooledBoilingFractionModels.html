class  SahaZuber
 Calculate the temperature of onset of nucleate boiling according to the model by N. SahaZuber, G.R. Warrier, and V.K. Dhir, "Onset of Nucleate Boiling and Active Nucleation Site Density During Subcooled Flow Boiling," J. Heat Transfer, 124, 717-728, 2002.. This model should only to be used in the following parameter range: p = 0.1 - 13.8 MPa massFlux = 95 - 2760 kg/m2/s (i.e. ~ 0.1 - 2.7 m/s for water at ~ 1000 kg/m3) heatFlux = 0.28 - 1.89 MW/m^2.
