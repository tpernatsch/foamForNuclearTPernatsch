Detailed Description

template<class BasicTurbulenceModel>
class Foam::RASModels::porousKEpsilon2PhaseCorrected< BasicTurbulenceModel >

Same as porousKEpsiolon but turbulent intensity correlation in the form turbulenceIntensityCoeff*Reynolds^turbulenceIntensityExp + turbulenceIntensityAlphaCoeff * (1-alpha), where alpha is the phase fraction.
