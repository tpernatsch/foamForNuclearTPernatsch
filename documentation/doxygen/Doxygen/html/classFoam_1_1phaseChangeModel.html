If phase 1 gains enthalpy from the disappearance of phase 2 (e.g. if

phase 1 is liquid, 2 is vapour and the vapour is condensing) then the enthalpy added to phase 1 is at saturation (i.e. the interfacial enthalpy, he1I). If phase 1 loses enthalpy from its own disappearance (e.g. if phase 1 is liquid, 2 is vapour and the liquid is boiling) then the enthalpy is removed from phase 1 at its current enthalpy (he1). This strategy is to prevent possible thermal run-aways. Note that beacuse of this formulation, the enthalpy gain term can be treated implicitly but the loss term must be treated explcitly.
