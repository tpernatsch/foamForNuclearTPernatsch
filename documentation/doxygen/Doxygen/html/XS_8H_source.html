39  Foam::XS
40 
41 Description
42  Class for XS parametrization and other nuclear data. Nuclear data are always
43  provided in MKSA units and not in cm.
44 
45 See 2D_MSFR or 3D_SmallESFR of Godiva_SN for exhaustive examples.
46 
47 <div class="groupHeader">
48 \table
49  Parameter | Type | Req'd | Default | Description
50  energyGroups | Integer | No | 1 | Number of energy groups
51  precGroups | Integer | No | 1 | Number of precursor groups
52  legendreMoments | Integer | No | 0 | Number of Legendre moments
53  fastNeutrons | Boolean | No | True | Flag for fast neutron spectrum, if true, use log(Tfuel) law, else use sqrt(Tfuel) law
54  adjustDiscFactors | Boolean | No | False | Flag to apply the discontinuity factor adjustement
55  useGivenDiscFactors | Boolean | No | False | Flag to use homogeneous discontinuity factors provided in state/zone
56  groupsWoDF | List<int> | No | Empty | List of energy group index to not apply discontinuity factors
57  doNotParametrize | List<int> | No | Empty | List of energy group index to not use parametrization (use only the values from the reference state)
58  ScNo | Scalar | No | 1 | Schmidt number for diffusion of precursors
59  polyharmonicSplineMode | Label | No | 1 (linear) | Polyharmonic spline function mode (1: \f$ r \f$; 2: \f$ r^2 ln(r) \f$; 3: \f$ r^3 \f$; 4: \f$ r^4 ln(r) \f$)
60  axialOrientation | Vector | No | (0,0,1) | Fuel axial orientation
61  isLowMemory | Boolean | No | False | Low memory flag, useful for SN solver
62 \endtable
63 </div>
64 
65 The following table lists the possible perturb state keywords to be used in the
66 state dictionaries. it is possible to use multiple parameters in the same state
67 (e.g Tfuel and rhoCool).
68 
69 <div class="groupHeader">
70 \table
71  Parameter | Type | Req'd | Default | Description
72  Tfuel | Scalar | No | 0.01 | Fuel temperature in K
73  Tclad | Scalar | No | 0 | Cladding temperature in K
74  Tcool | Scalar | No | 0 | Coolant temperature in K
75  TstructMech | Scalar | No | 0 | Mechanical structure temperature in K
76  rhoCool | Scalar | No | 0 | Coolant density in kg/m3
77  axExp | Scalar | No | 0 | Axial expansion from nominal
78  radExp | Scalar | No | 0 | Radial expansion from nominal
79 \endtable
80 </div>
81 
82 Here follow the list of group wise nuclear data for each cellzone to be provided
83 for GeN-Foam. Each subscript \f$g\f$ refers the gth energy group. Each \f$k\f$
84 refers to the kth precursor group.
85 
86 <div class="groupHeader">
87 \table
88  GeN-Foam Parameter | Param | Req'd | Default | Notation | Description
89  fuelFraction | Constant | No | 1 | \f$ \alpha_{fuel} \f$ | Volume of fuel per lattice volume
90  secondaryPowerVolumeFraction | Constant | No | 1 | | Volume fraction of secondary power-producing structure e.g., graphite in MSRs
91  fractionToSecondaryPower | Constant | No | 0 | | Fraction of total power that goes to secondary power-producing structure
92  IV | Constant | Yes | - | \f$ 1/v_g \f$ | Inverse velocity
93  D | Variable | Yes | - | \f$ D_g \f$ | Diffusion coefficient
94  nuSigmaEff | Variable | Yes | - | \f$ \nu \Sigma_{f,eff, g} \f$ | Fission neutrons cross-section
95  sigmaPow | Variable | Yes | - | \f$ \kappa \Sigma_{f, g} \f$ | Fission energy release cross-section
96  sigmaRemoval | Variable | Yes | - | \f$ \Sigma_{r, g} \f$ | Removal cross-section (\f$\Sigma_{abs} + \Sigma_{capture} + \Sigma_{s, g \rightarrow g}\f$)
97  scatteringMatrixP0 | Variable | Yes | - | \f$ \Sigma_{s, g \rightarrow g'} \f$ | Scattering cross-section matrix
98  chiPrompt | Constant | Yes | - | \f$ \chi_{p, g} \f$ | Prompt fission emission spectrum
99  chiDelayed | Constant | Yes | - | \f$ \chi_{d, g} \f$ | Delayed fission spectrum
100  Beta | Constant | Yes | - | \f$ \beta_k \f$ | Delayed neutron fraction
101  BetaTot | Constant | Yes | - | \f$ \beta_{tot} \f$ | Total delayed neutron fraction
102  lambda | Constant | Yes | - | \f$ \lambda_k \f$ | Precursor decay constant
103  discFactor | Constant | Yes | - | \f$ \gamma_g \f$ | Discontinuity factors
104  integralFlux | Constant | Yes | - | \f$ \Phi_g \f$ | Integral flux for adapting disc factors
105 \endtable
106 </div>

109 \verbatim
110 states

114  // Reference parameters
115  Tfuel 1000;
116  rhoCool 1000;
117  // Assume the other parameters are not used
118 
119  zones
120  (
121  core
122  {
123  fuelFraction ...;
124  IV ...;
125  ...
126  }
127  reflector
128  {
129  ...
130  }
131  );
132  }
133  Tfuel1200K // Additional state, arbitrary state name
134  {
135  // Perturb only Tfuel
136  Tfuel 1200;
137  // Assume by default that rhoCool is not perturb and uses rhoCool = 1000
138 
139  zones

143  ...
144  }
145  );
