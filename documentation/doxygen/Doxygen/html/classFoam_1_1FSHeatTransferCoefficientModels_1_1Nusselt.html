Detailed Description

Heat transfer coefficient for forced convective flows that is computed starting from the Nusselt, which is turn obtained via correlation in the form.

\[ Nu = A + B \times Re^C Pr^D \left( \frac{T_w}{T_b} \right)^E \]

where:

\( Re \) = Reynolds number (superficial in two-phase) of the fluid
\( Pr \) = Prandtl number of the fluid
\( T_w \) = Wall temperature
\( T_b \) = Bulk temperature
\( A, B, C, D, E \) = Selectable constants 
Example of mandatory dictionary entries:
\verbatim
    const   4;
    coeff   0.01;
    expRe   0.8;
    expPr   0.8;

Example using wall/fluid temperature ratio from: Walton 1992, (10) Wolf-McCarthy II \( Nu = 0.023 Re^{0.8} Pr^{0.4} \left( \frac{T_w}{T_b} \right)^{-0.3} \) with Re = [7800; 1.55e6] and \( T_w/T_b \) = [1.5; 2.8] 

    const   0;
    coeff   0.023;
    expRe   0.8;
    expPr   0.4;
    expTc   -0.3;
