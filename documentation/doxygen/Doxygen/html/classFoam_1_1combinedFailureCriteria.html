Detailed Description

Criterion used to combine multiple failure criteria. Failure is supposed to occur when one of the criteria declare failure.

Usage
In solverDict file: 
materials
{
    cladding
    {
        failureModel    combined;
        stopIfFailed    on;
        failureModelOptions
        {
            patchNames      ( "cladOuter" "cladInner" );
            criteria        ( ZyOverstressBISON ZyPlasticInstabilityBISON )
        }
    }
}
