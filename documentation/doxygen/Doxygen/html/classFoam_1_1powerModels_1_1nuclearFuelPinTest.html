Detailed Description

Same as nuclearFuelPin. This is a dummy class used in the ESFR regression test to verify capability to handle multiple "nuclear" power models.

Authors: Stefan Radman (stefa.nosp@m.n.ra.nosp@m.dman@.nosp@m.epfl.nosp@m..ch / stefa.nosp@m.nrad.nosp@m.man92.nosp@m.@gma.nosp@m.il.co.nosp@m.m), Carlo Fiorina (carlo.nosp@m..fio.nosp@m.rina@.nosp@m.outl.nosp@m.ook.c.nosp@m.om / carlo.nosp@m..fio.nosp@m.rina@.nosp@m.epfl.nosp@m..ch)
