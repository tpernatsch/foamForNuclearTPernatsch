Detailed Description

Heat transfer coefficient for Inverted Annular Flow - for the liquid phase. This code cooperate with the CachardVapourFSHeatTransferCoefficient. Warning, this model has been coded for rod bundle, especially for delta model, the thickness of the film of vapor.
