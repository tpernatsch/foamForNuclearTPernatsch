38 Class
39  Foam::phaseChangeModels::forcedConstantPhaseChange
40 
41 Description
42  Phase change models that compute mass transfer based on interfacial
43  heat fluxes. There are three possible modes that can be selected:
44 
45  - conductionLimited: dmdt_ is computed so to conserve total energy
46  transfer across interface if the interfacial heat fluxes do not
47  balance out. It q1i and q2i are the respective heat fluxes form the
48  bulk of phase 1/2 to the interface, then dmdt_ = (q1i+q2i)/L with L
49  being the latent heat. This is the approach found in TRACE
50  (check theory manual, https://www.nrc.gov/docs/ML0710/ML071000097.pdf)
51  but it is not suited if there is a massive difference in the volumetric
52  heat capacity (J/K/m3) of the phases (such as in the case of sodium, due
53  to the density difference of a factor ~ 2000). It can be very unstable
54  and not converge at all in such scenarios;
55 
56  - twoPhaseDriven: evaporation is driven uniquely by liquid superheat and
57  condensation is driven uniquely by vapor undercooling. There is no need
58  to specify which phase is liquid and which is vapour in the
59  phaseProperties dict, as this information is contained in the latent
60  heat L (positive if phase1 is liquid and 2 is vapour, negative
61  otherwise);
62 
63  - onePhaseDriven: both evaporation and condensation are driven uniquely
64  by one phase's superheat or cooling. Implemented as a counterpart to
65  twoPhaseDriven.
66 
67  The latent heat is computed as a difference of the enthalpies of formation
68  (specified in the thermoPhysicalProperties of each phase under the Hf
69  keyword). Thus, the vapour phase is the phase with the highest enthalpy of
70  formation. The latent heat can be adjusted as described in the TRACE theory
71  manual to avoid thermal-run-aways in particular scenarios. This feature can
72  be enabled via the correctLatentHeat flag in the phaseChangeModel subDict,
73  but it is not recommended if dealing with phases with a low volumetric
74  heat capacity, as described before (e.g. Sodium).
75 
76  Dict example
77  \verbatim
78  phaseChangeModel
79  {
80  type forcedConstant;
81  mode onePhaseDriven; //- conductionLimited;//twoPhaseDriven;
82  drivingPhase "phaseName"; //- (required only for onePhaseDriven)
83  correctLatentHeat false; //- defaults to false
84 
85  saturationModel //- Unrelated to the forcedConstant model
86  {
87  type "BrowningPotter";
88  }
89  }
90  \endverbatim
