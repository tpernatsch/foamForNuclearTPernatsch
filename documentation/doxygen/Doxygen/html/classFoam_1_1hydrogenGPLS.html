Detailed Description

hydrogenGPLS (Guisson-Poussard-Le Saux) mechanical behavioral law Viscoplastic behavior for fresh and irradiated zyr4 under RIA loading conditions. Used in ALCYONE (CEA - FRANCE) fuel code for RIA simulations. NOT for base irradiation. Elastic behavior is assumed isotropic and is given by Hooke's Law. Viscoplastic behavior takes into account the orthotropic nature of irradiated ZYR. Make uses of the Hill Tensor and Hill's equivalent strain. No stress threshold between elastic and viscoplastic flow.

The fluence (phi) is required as an input in 1e25 n.m-2 to take into account irradiation effect. IE., put 1 for 1e25

A second (non physical) parameter zeta is needed. In the model, the parameter zeta corresponds to the normalised axial position in the (total) fuel rod (0= bottom, 1=top) Introduced to take into account the temperature axial profile during base irradiation RIA test pulses in research reactor are typically done on refabricated fuels elements previously irradiated in commercial reactors The strength modulus K is weakly dependant on this parameter Default value is 0.5

Validity range: fluence/BU up to 10e25 .nm-2 / 64 GWd/t(U) 20°C < T < 1100 °C -— (in practice, in RIA simulations, we can go over 1100 °C) 3e-4 < ddt(epsilon) < 5 .s-1

from: A model to describe the anisotropic viscoplastic mechanical behavior of fresh and irradiated Zircaloy-4 fuel claddings under RIA loading conditions Journal of Nuclear Materials, vol 378.1, 60-69, 2008 https://doi.org/10.1016/j.jnucmat.2008.04.017

Le Saux thesis (french - english) : https://www.theses.fr/2008ENMP1608

Interested reader may also refers to: The PROMETRA Program: Fuel Cladding Mechanical Behavior under High Strain Rate Nuclear Technology, vol 157.3, 215-229, 2007 https://doi.org/10.13182/NT07-A3814

Usage
rheology byMaterial;

...

// List of materials, one per cellZone.
materials
{
    ...

    cladding
    {
        material zircaloy;
        ...

        rheologyModel hydrogenGPLS;

        rheologyModelOptions
        {
            phi      1;
            zeta    0.5;

            error 1e-6; //- Optionnal. Tolerance for exiting the newton-rahpson iterations (default is 1e-6)
            max_iter 10000; //- Optional. Max number of newton-rahpson iterations (default is 10 000)
            relax 0.01; //- Optional. Relaxation factor for newton raphson iterations (default is 0.01)
            theta 1; //- Optional. Theta value (between 0 and 1) for the integration scheme. 0 --> fully explicit (Forward Euler). 
                                                                                             1 --> fully implicit (Backard Euler)
                                                                                             0.5 --> semi-implicit (mid point rule / Cranck-Nicholson)
            Fully explicit is not advised. Use 1 or 0.5. The latter is the most efficient and robust scheme.
            More infos at https://tfel.sourceforge.net/documents/mfront/behaviours.pdf (french).
        }
    }

    ...
}
