Detailed Description

Coupled boundary condition that forces continuity (for the temperature field) between two bodies with different material properties.

Usage
fuelOuter
{
    type            temperatureCoupled;
    patchType       regionCoupledOFFBEAT;
    coupled         true;
    value           $internalField;
}
