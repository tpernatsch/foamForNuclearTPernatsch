24 Class
25  Foam::offbeatTime
26 
27 Description
28  Manage time in OFFBEAT in days/hours/seconds as decided by the user in
29  controlDict.
30 
31  The user should be aware that the choice of time unit must be consistent
32  across the input files, i.e. all time dependent tables provided in the
33  solverDict or in the boundary conditions must be provided accordingly to the
34  time unit selected in the controlDict.
35 
36 Usage
37  In controlDict
38  \verbatim
39  ...
40 
41  userTime
42  {
43  // type is seconds by default
44  type seconds;//hours;//days;
45  }
46 
47  ...
48  \endverbatim
