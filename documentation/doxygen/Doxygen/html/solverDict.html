Setting the solverDict file

The entire simulation, including the choice of governing equations, physical models, material properties, power history, etc., is defined by the solverDict located in the constant subdirectory of the case.

The first entries required by solverDict define the type of problem and underlying physics to solve for.

Keyword Description Type
thermalSolver Select the solution type for the heat transfer word
mechanicsSolver Select the solution type for the momentum balance word
neutronicsSolver Select the solution type for the neutron flux distribution word
gapGas Select the gapGas model word
heatSourceModel Select the model type for the heat source word
fastFluxModel Select the model type for the fast flux and fast fluence word
burnup Select the model type for the burnup word
fgr Select the model type for the fission gas release word
materialProperties Select the material property treatement word
rheology Select the rheology law treatement word
mapperModel Select the type of 3D to 1D mapping word

For most underlying physics or models, an additional subdictionary might be required to further define the physics and solution methods.
