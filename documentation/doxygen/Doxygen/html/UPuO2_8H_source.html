27 Description
28  UPuO2 material class.
29 
30  The thermomechanical properties are taken from different sources, as BISON
31  manual, FRAPCON manual or RELAP manual.
32 
33  The material property and behavioral models can selected with the specific
34  keywords. Otherwise, default models will be used.
35 
36 Usage
37  In solverDict file:
38  \verbatim
39  materials
40  {
41  //- Name of cellZone with UPuO2 material model
42  fuel
43  {
44  material UPuO2;
45 
46  densityModel UPuO2Constant;
47  heatCapacityModel UPuO2MATPRO;
48  conductivityModel UPuO2;
49  emissivityModel UO2RELAP;
50  YoungModulusModel UPuO2MATPRO;
51  PoissonRatioModel UPuO2Constant;
52  thermalExpansionModel UPuO2MATPRO;
53 
54  densificationModel UO2FRAPCON;
55  swellingModel UO2FRAPCON;
56  relocationModel UO2FRAPCON;
57  failureModel none;
58  }
59  ...
60 
61  }
62  \endverbatim

67 \todo
68 
69  - No correlation for (U,Pu)O2 emissivity is available. It is therefore
70  recommended to use the one for UO2 fuel. Source:
71  (https://www.pnnl.gov/main/publications/external/technical_reports/PNNL-19417.pdf).
72  - Based on the limited available in-reactor data for MOX, the same
73  correlations for UO2 and UPuO2 are used for densification and swelling.
74  Source: MATPROv11
75  - The same goes for the relocation, no model for MOX is available
76  and therefore the UO2 model is used.
