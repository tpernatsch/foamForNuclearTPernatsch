41 Description
42  myMULES: Multidimensional universal limiter for explicit solution.
43 
44  Solve a convective-only transport equation using an explicit universal
45  multi-dimensional limiter.
46 
47  Parameters are the variable to solve, the normal convective flux and the
48  actual explicit flux of the variable which is also used to return limited
49  flux used in the bounded-solution.
50  This version is virtually indentical to the MULES present in OpenFOAM6.
51  The main difference consists in the option to provide a space-dependent
52  limiter field, something which is absent in the v1812 OpenFOAM version of
53  MULES.
54  Modified by Stefan Radman (stefan.radman@epfl.ch/stefanradman92@gmail.com)
