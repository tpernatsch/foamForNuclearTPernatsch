39  Foam::timeProfile

41 Description
42  Base class for time profile functions. This object embeds the OpenFOAM
43  Function1 object used to represents tables. timeProfile is also able to
44  input data from an FMI.
45 
46  Example of time dependant source entries:
47  \verbatim
48  // Using table
49  externalReactivityTimeProfile
50  {
51  type table;
52  startTime 100;
53  table table
54  (
55  ( 0 0)
56  ( 1 0.0005767131 ) //- i.e. 57.67131 pcm, == 0.2*Beta
57  );
58  }
59 
60  // Using FMI
61  externalReactivityTimeProfile
62  {
63  type fmi;
64  nameFromFMU gfExtReact;
65  initialValue 0.0;
66  }
67  \endverbatim

70  Thomas Guilbaud <thomas.guilbaud@epfl.ch;>, EPFL/Transmutex SA (Swizerland)
