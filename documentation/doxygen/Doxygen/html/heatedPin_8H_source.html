38 Class
39  Foam::powerModels::heatedPin
40 
41 Description
42  Model for representing a heated pin with constant material properties that
43  is coupled to the fluid(s) via a convective boundary condition. The
44  equation is solved via the finite volume method.
45 
46 
47 \par Options
48 
49  Parameters in the powerModel subdictionary for `heatedPin`:
50 
51  - <b>`innerRadius`</b> - Pin inner radius.
52  - <b>`outerRadius`</b> - Pin outer radius.
53  - <b>`meshSize`</b> - Pin radial mesh.
54  - <b>`rho`</b> - Pin density in kg/m3.
55  - <b>`Cp`</b> - Pin specific heat capacity in J/kg/K
56  - <b>`rhoCp`</b> - If `rho` and `Cp` are not provided `rhoCp` can be used.
57  - <b>`k`</b> - Pin thermal conductivity.
58  - <b>`T`</b> - Pin initial temperature.
