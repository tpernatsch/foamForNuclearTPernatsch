39  Foam::powerModels::fixedPower
40 
41 Description
42  Describes a generic structure with a constant or time depdendent internal
43  power production.
44  Solves an energy equation for the structure, updating the average
45  structure temperature (assumed equal to the structure surface temperature
46  for fluid heat transfer purposes).
47 
48 Usage
49  \verbatim
50  powerModel
51  {
52  type fixedPower;
53  volumetricArea 100;
54  T 652.15;
55  Cp 500;
56  rho 7700;
57  powerDensity 4.5e8;
58  powerTimeProfile // Optional
59  {
60  type table;
61  startTime 0;
62  table table
63  (
64  ( 0 4.5e8 )
65  ( 100 4.5e7 )
66  );
67  }
68  }

70  // Using FMI input
