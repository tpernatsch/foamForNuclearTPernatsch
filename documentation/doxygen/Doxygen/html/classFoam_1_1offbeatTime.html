Detailed Description

Manage time in OFFBEAT in days/hours/seconds as decided by the user in controlDict.

The user should be aware that the choice of time unit must be consistent across the input files, i.e. all time dependent tables provided in the solverDict or in the boundary conditions must be provided accordingly to the time unit selected in the controlDict.

In controlDict 
...

userTime
{
    // type is seconds by default
    type seconds;//hours;//days;
}
