Detailed Description

yield stress model from WGFS RIA fuel codes benchmark Phase II specifications. https://www.oecd-nea.org/jcms/pl_19704/reactivity-initiated-accident-ria-fuel-codes-benchmark-phase-ii-volume-2-task-no-1-specifications?details=true

The model itself comes from the FRAPTRAN fuel code and the MATPRO database. The yield stress is dependant on temperature, fast neutronce fluence, Cold Work amount and strain rate.
