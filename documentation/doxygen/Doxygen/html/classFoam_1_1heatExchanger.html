In two-phase solvers :

HT = H1*frac1*T1 + H2*frac2*T2 H = H1*frac1 + H2*frac2 ! In a mono-phase solver : /*! HT = H*T H = H THX is the field to be set according to the updated HX surface temperatures with might mapping magic

The max against 1e-69 is just to avoid the case in which the

heat transfer coefficient on both side is 0 (which results in Ap*As = 1.0), a case in which no heat is to be transferred via the HX but that would result in a division by 0 if not accounted for. Please note that in such a scenario THX is set to 0 yet it does not matter as said earlier, this only happens where the heat transfer coefficient 0 or very close to it

Kinda useless but whatever, at least the fields looks nicer in paraView

if you set the boundaries
