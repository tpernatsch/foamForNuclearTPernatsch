Detailed Description

Model to compute pore velocity within MOX fuel with the correlation provided by Lackey et Al.

Ref: W. J. Lackey, F. J. Homan & A. R. Olsen (1972) Porosity and Actinide Redistribution During Irradiation of (U, Pu)O2, Nuclear Technology, 16:1, 120-142, DOI: 10.13182/NT72-A31181

Usage
In solverDict file: 
materials
{
    fuel
    {
        material UPuO2;

        ...

        poreVelocityModel     MOXLackey;
        // Multiplicator for pore velocity
        // alphaPoreVelocity 1;
    }

    ...
}
