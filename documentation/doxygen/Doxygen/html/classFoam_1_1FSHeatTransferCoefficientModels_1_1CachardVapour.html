Detailed Description

Heat transfer coefficient for Inverted Annular Flow - for the vapour phase. This code cooperate with the CachardLiquidFSHeatTransferCoefficient. Warning, this model has been coded for rod bundle, especially for the delta model, the thickness of the film of vapor.

Author: Gauthier LAZARE - gauth.nosp@m.ier..nosp@m.lazar.nosp@m.e@gm.nosp@m.ail.c.nosp@m.om
