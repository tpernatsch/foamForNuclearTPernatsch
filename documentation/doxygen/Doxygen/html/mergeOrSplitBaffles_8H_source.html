39  Foam::insertDuplicateMerge
40 
41 Description
42  Detects boundary faces that share points (baffles). Either merges them or
43  duplicate the points.
44 
45 Note
46  - can only handle pairwise boundary faces. So three faces using
47  the same points is not handled (is illegal mesh anyway)
48 
49  - surfaces consisting of duplicate faces can be topologically split
50  if the points on the interior of the surface cannot walk to all the
51  cells that use them in one go.
52 
53  - Parallel operation (where duplicate face is perpendicular to a coupled
54  boundary) is supported but not really tested.
55  (Note that coupled faces themselves are not seen as duplicate faces)
