Detailed Description

Parent class for swelling model.

The parent class typeName is "none". If selected in the solverDict the swelling is not considered, but the swelling field 'epsilonSwelling' is created and added to registry.

If the 'epsilonSwelling' file is present in the starting time folder, the internal field and boundary conditions are set according to the file.

Otherwise, the field is set to 0 in each cell, with zeroGradient BCs in all non-empty/-wedge patches.

Usage
In solverDict file: 
materials
{
    fuel
    {
        material UO2;

        ...

        swellingModel     none;
    }

    ...
}
