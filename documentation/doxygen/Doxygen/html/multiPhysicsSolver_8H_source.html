38 Class
39  Foam::multiPhysicsSolver
40 
41 Description
42  This class creates a multiphysics tightly coupled loop, made of an arbitrary
43  number of physics. The class member-functions are inherited from solver.H
44  and are the same as those of the other solvers. Each member function consists
45  of a loop where the same member function is called iteratively for all the
46  solvers included in the multiPhysicsSolver. Note that another multiphysicsSolver
47  can be created within a multiphysicsSolver, hence creating a hierarchical
48  structure which might be helpful for multi-scale problems.
49 
50 Usage
51  In multiRegionCouplingDict, the multiPhysicsSolvers subDict is used to create a
52  multiPhysicsSolver
53 
54  \verbatim
55  multiPhysicsSolvers
56  {
57  multiPhysicsSolver1 //multiPhysicsSolverName
58  {
59  solvers // list of solvers
60  {
61  regionName solverName;
62  fluidRegion onePhase;
63  neutroRegion diffusionNeutronics;
64  multiPhysicsSolver2 multiPhysicsSolver;
65  }
66  minResidual 0.00005; // residual after which the iteration is ended
67  maxIterations 3; // maximum number of iterations before the loop is ended
68  includeFluidMechanicsInLoop false; //defaulted to false
69  }
70  }
71 
72  multiPhysicsSolver2
73  {
74  ...
75  }
76  \endverbatim
77 
78  If includeFluidMechanicsInLoop entry is set to false (default value), for the thermal-hydraulics
79  solvers only the energy is solved iteratively with the other physics, while the fluid-mechanics
80  is solved only once at the beginning of the iteration. This is done so that useless
81  fluid-mechanics iterations are solved.
