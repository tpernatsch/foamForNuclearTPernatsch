Detailed Description

Derived from the base heatSource class, this class act as the parent class for all heat source models that define the linear heat generation rate (lhgr) as an additional field.

Source files

  • heatSource.C
TODO
  • The lhgr might be needed by some models such as the relocation, therefore it might be useful to have it as a field in the registry. Alternatively, one could make the heatSource class an IOObject and ask directly for the lhgr with a function. In this case having the lhgr as a vol field might not be necessary.
