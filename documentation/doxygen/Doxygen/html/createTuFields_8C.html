Detailed Description

This application is intended to be used for the coupling with the TRANSURANUS 1.5D fuel performance code. It simply reads TU fields from a dictionary located in "$FOAM_CASE/system/TuOFFBEATdict" and creates OFFBEAT fields performing due interpolations on the OFFBEAT mesh.
