User documentation for timeDependentAxialProfileHTC fvPatchField class

For a list of fvPatchField classes specifically developed for OFFBEAT, please refer to the fieldsAndBCs page.

Summary

The timeDependentAxialProfileHTC boundary condition allows to simulate an heat sink boundary defined by a convective heat transfer coefficient \(h\) and a sink temperature \(T_0\) that vary axially and during time.

This boundary condition computes the temperature \(T\) to be applied to the patch using the following expression for heat flux \(q"\):

\[ q" = h\cdot(T-T_0) \]

Where \(q"\) is computed from the Fourier's Law:

\[ q" = -k\cdot \nabla T \]

Note
- The axial locations provided to this boundary conditions are NOT normalized but absolute values expressed in \(m\).
- The \(T_0\) values provided to this boundary conditions are expressed in \(K\).
- The \(h\) values provided to this boundary conditions are expressed in \(\frac{W}{m^2 K}\).

Examples

To apply the timeDependentAxialProfileHTC boundary condition to a given patch, the following example can be used as a template:


  cladOuter
  {
      type            timeDependentAxialProfileHTC;
      axialProfileDict
      {
          timePoints     (0 1e3 1.261e8);
          axialLocations (0.0 1.0 2.0 3.2);
          hData          (
                              (5e3 5.01e3 5.02e3 5.01e3)
                              (5e3 5.01e3 5.02e3 5.01e3)
                              (5e3 5.01e3 5.02e3 5.01e3)
                          );
          T0Data          (
                              (350 370 380 365)
                              (360 380 370 360)
                              (340 360 390 376)
                          );
          axialInterpolationMethod "linear";
          timeInterpolationMethod "linear";
      }
      value           $internalField;
  }
