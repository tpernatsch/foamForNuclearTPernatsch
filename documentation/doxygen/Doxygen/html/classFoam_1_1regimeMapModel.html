DynamicList<DynamicList<Tuple2<label,scalar> > > regimeLabelCoeffs_
protected

For eaech mesh cell, this consists of a list of tuples of parameters.

for each regime that exists in said cell, wherein the first element in each tuple is the regime label and the second the regime coefficient. It is handled via DynamicLists as they are significantly faster to allocate, append to, and clear than regular lists (which is something that is done quite often for this object)
