Detailed Description

Run-time selectable class to handle the thermal description (i.e. energy source/sinks) of a structure. It returns a heat source term to the main solver be used in the energy equations.

Author: Stefan Radman (stefa.nosp@m.n.ra.nosp@m.dman@.nosp@m.epfl.nosp@m..ch / stefa.nosp@m.nrad.nosp@m.man92.nosp@m.@gma.nosp@m.il.co.nosp@m.m)

For some models it is mandatory, others (e.g. the pin ones) should.

allow for the option for the interfacial area to be computed starting from other powerModel geometric properties (e.g. again, for a pin geometry, the interfacial area is directly linked to the volume-averaged pin volume fraction and the pin outermost radius).
