Detailed Description

By selecting this constant model the velocity is read from the previous time step folder. Useful for user-defined velocity functions (e.g. by means of codedStream-type initial conditions).

Usage
In solverDict file: 
materials
{
    fuel
    {
        material UPuO2;

        ...

        poreVelocityModel     constant;
    }

    ...
}
