Detailed Description

Mother class for pore velocity models. If selected, sets the velocity to zero.

Usage
In solverDict file: 
materials
{
    fuel
    {
        material UPuO2;

        ...

        poreVelocityModel     none;
        // Multiplicator for pore velocity
        // alphaPoreVelocity 1;
    }

    ...
}
