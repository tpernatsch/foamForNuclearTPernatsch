User documentation for none fission gas release class

For general instructions on the modeling of the fission gas release in OFFBEAT see here.

As the name implies, the none fission gas release class in OFFBEAT allows you to switch off the fgr models and have a simulation where fgr production, release and related gaseous swelling are not considered. This means that no additional fields are created.

Note on additional fields

Although with the none fgr class no additional fields are created for the fission gases itself (e.g. concentration, release fraction etc.) the basic fgr class generates the following fields:

- grainRadius and oxygenMetalRatio
- interGranularSwelling and interGranularSwelling

While this specific aspect might change in future version of OFFBEAT, at the moment selecting none means that the previously mentioned fields will be created and will remain constant during the simulation.

Usage

To use the none fgr model in OFFBEAT, the user needs to specify it in the solverDict dictionary using the following syntax:


  fgr none;
