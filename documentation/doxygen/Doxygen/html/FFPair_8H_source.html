41 Description
42  Class to handle dimensionless numbers that characterise the system, e.g.
43  Reynolds, etc. While some can (rightfully) think that some of these numbers
44  should be directly members of other classes (e.g., Reynolds of fluids
45  should be in the fluid class), in general these numbers depend on a
46  multitude of parameters. You cannot define a Reynolds for a fluid by
47  itself, it needs to be geometrically constratined in a certain domain
48  (so that a hydraulic diameter can be defined), so it is not properly
49  "just" of the fluid. While this logic can of course be debate, I wanted
50  to keep it simple and not start dispersing dimensionless numbers randomly
51  around the code.
