Detailed Description

Model to compute pore velocity with the correlation provided by Clement and Finnis.

Ref: C.F. Clement, M.W. Finnis, Plutonium redistribution in mixed oxide (U, Pu)O2 nuclear fuel elements, Journal of Nuclear Materials, Volume 75, Issue 1, 1978, Pages 193-200, ISSN 0022-3115, https://doi.org/10.1016/0022-3115(78)90044-2.

Usage
In solverDict file: 
materials
{
    fuel
    {
        material UPuO2;

        ...

        poreVelocityModel     MOXClementFinnis;
        // Multiplicator for pore velocity
        // alphaPoreVelocity 1;
    }

    ...
}

In addition, a correction factor can be defined to correct the velocity (default value is 1.0).
