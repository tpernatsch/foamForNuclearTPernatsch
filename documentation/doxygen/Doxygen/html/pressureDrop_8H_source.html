38 Class
39  Foam::functionObjects::pressureDrop
40 
41 Group
42  grpFieldFunctionObjects
43 
44 Description
45  Calculates the spatial minimum and maximum extents of a field
46 
47  The extents are derived from the bound box limits after identifying the
48  locations where field values exceed the user-supplied threshold value.
49 
50 Usage
51  Example of function object specification:
52  \verbatim
53  pressureDrop1
54  {
55  type pressureDrop;
56  libs ("libfieldFunctionObjects.so");
57  ...
58  writeToFile yes;
59  log yes;
60  upstreamRegionType patch/faceSet;
61  upstreamRegion inlet;
62  downstreamRegionType faceSet;
63  downstreamRegion outlet;
64  pressure p_rgh
65  }
66  \endverbatim
67 
68  Where the entries comprise:
69  \table
70  Property | Description | Required | Default value
71  type | type name: pressureDrop | yes |
72  writeToFile | write extents data to file | no | yes
73  log | write extents data to standard output | no | yes
74  regionType | Either cellZone or patch | Yes
75  patches | list of patches to process | depends on regionType
76  cellZones | list of cellZones to process | depends on regionType
77  \endtable
78 
79  Output data is written to the file <timeDir>/pressureDrop.dat
80 
81 Note
82  For non-scalar fields, the magnitude of the field is employed and compared
83  to the threshold value.
84 
85 See also
