Detailed Description

Class for the beta phase transition of Zy-based claddings, dynamic approach derived from "A.R. Massih, Transformation kinetics of zirconium alloys under non-isothermal conditions, Journal of Nuclear Materials, Volume 384, Issue 3, 2009, Pages 330-335, ISSN 0022-3115, https://doi.org/10.1016/j.jnucmat.2008.11.033. (https://www.sciencedirect.com/science/article/pii/S0022311508007654).
