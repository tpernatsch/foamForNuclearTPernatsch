24 Class
25  Foam::mechanicsSubSolver
26 
27 Description
28  Parent class for mechanics solvers.
29  It can be selected with the "fromLatestTime" typeName in solverDict.
30  In this case, the displacement field "D" is read from latest time folder
31  and no equation is solved for. If the file is not present, the displacement
32  is set to (0 0 0) by default with zero-gradient BCs.
33 
34 Usage
35  In solverDict file:
36  \verbatim
37  mechanicsSolver fromLatestTime;
38 
39  mechanicsOptions
40  {
41  // Print summary of boundary-forces at each iteration
42  forceSummary false;
43 
44  // Creates cylindrical stress and displacement field (for debugging)
45  cylindricalStress false;
46 
47  // Apply RhieChowCorrection to stabilize momentum equation (it should
48  // be activated in most situations)
49  RhieChowCorrection true;
50 
51  // Additional subDict for multi-material cases
52  multiMaterialCorrection
53  {
54  ...
55  }
56 
57  }
58  \endverbatim
