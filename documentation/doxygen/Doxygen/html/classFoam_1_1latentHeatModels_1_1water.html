Detailed Description

This class describes the latent heat of vaporization of water in the 0.01-350 C range. It was obtained from a fit (in the form of L = A+B*log(C-T) with T being the liquid temperature (K)) of NIST water data at saturation found at: https://www.nist.gov/system/files/documents/srd/NISTIR5078-Tab1.pdf.

It performs reasonably well up to ~ 365 C as well, considering that the critical water temperature is 375.16 C (at which point the latent heat becomes 0, but is limited for obvious numerical reasons as this code is not meant for sub-supercritical fluid transition simulations)

Author: Stefan Radman (sradm.nosp@m.an@p.nosp@m.m.me / stefa.nosp@m.n.ra.nosp@m.dman@.nosp@m.epfl.nosp@m..ch)
