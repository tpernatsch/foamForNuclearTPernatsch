Detailed Description

Stops the simulation when max(field1-field2) > 0 and prints out the simulation time. Both field1 and field2 must be volSclaraFields.

Usage
Example of function object specification: 
stopIfMaxFieldDiff1
{
    type                stopIfMaxFieldDiff;
    libs                ("libfieldFunctionObjects.so");
    ...
    writeToFile             yes;
    log                     yes;
    field1                  fieldName;
    field2                  fieldName;
}

Where the entries comprise:

type type name: stopIfMaxFieldDiff yes
writeToFile write extents data to file no yes
log write extents data to standard output no yes
field1 yes
field2 yes
Note
For non-scalar fields, the magnitude of the field is employed and compared to the threshold value.
