24 Class
25  Foam::corrosion
26 
27 Description
28  Base class for handling corrosion models. The user can select the corrosion
29  model specifying the keyword "corrosion" in the solver dictionary
30  (solverDict).
31 
32  The parent class typeName is "fromLatestTime". If selected in the solverDict
33  the corrosion does not evolve. However, the two corrosion fields
34  ('oxideThickness' and 'DOxideThickness') are created, added to the registry
35  and written at the end of the time step.
36 
37  If the files are present in the starting time folder, the internal field
38  and boundary conditions are set according to the file.
39 
40  Otherwise, the fields are set to 0 m in each cell, with zeroGradient BCs
41  in all non-empty/-wedge patches.
42 
43 Usage
44  In solverDict file:
45  \verbatim
46  corrosion fromLatestTime;
47 
48  corrosionOptions
49  {
50  // The updateMesh switch is set to true by default
51  updateMesh true;
52  }
53  \endverbatim
