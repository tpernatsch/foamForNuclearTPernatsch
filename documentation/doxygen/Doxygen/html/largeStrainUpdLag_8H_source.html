24 Class
25  Foam::largeStrainUpdLag
26 
27 Description
28  Finite- (or large-) strain mechanics sub-solver.
29 
30  It solves for incremental displacement 'DD' in an updated Lagrangian
31  configuration (i.e. the mesh is updated at the start of the time step).
32 
33  The geometric non-linearity (i.e. the inter-dependence between displacement
34  and geometric configuration) is taken care of by multiplying the stress
35  tensor (Cauchy) by relJ*relF.inv(), where relF is the relative deformation
36  gradient and relJ is its determinant.
37 
38  By default, the strain tensor takes into account the second order deformations:
39  \f[
40  epsilon = E = 0.5*(gradD + gradD.T() + gradD*gradD.T())
41  \f]
42 
43  However, with the "linearStrainTensor" keyword, the user can decide to force
44  a linear strain tensor:
45  \f[
46  epsilon = 0.5*(gradD + gradD.T())
47  \f]
48 
49 Usage
50  In solverDict file:
51  \verbatim
52  mechanicsSolver largeStrainUpdLag;
53 
54  mechanicsOptions
55  {
56  // Print summary of boundary-forces at each iteration
57  forceSummary false;
58 
59  // Force linear strain tensor
60  linearStrainTensor false;
61 
62  // Creates cylindrical stress and displacement field (for debugging)
63  cylindricalStress false;
64 
65  // Apply RhieChowCorrection to stabilize momentum equation (it should
66  // be activated in most situations)
67  RhieChowCorrection true;
68 
69  // Additional subDict for multi-material cases
70  multiMaterialCorrection
71  {
72  ...
73  }
74 
75  }
76  \endverbatim
