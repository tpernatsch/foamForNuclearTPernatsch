Detailed Description

myMULES: Multidimensional universal limiter for explicit solution.

Original source file myMULES.H

Solve a convective-only transport equation using an explicit universal multi-dimensional limiter.

Parameters are the variable to solve, the normal convective flux and the actual explicit flux of the variable which is also used to return limited flux used in the bounded-solution. This version is virtually indentical to the MULES present in OpenFOAM6. The main difference consists in the option to provide a space-dependent limiter field, something which is absent in the v1812 OpenFOAM version of MULES. Modified by Stefan Radman (stefa.nosp@m.n.ra.nosp@m.dman@.nosp@m.epfl.nosp@m..ch/stefanradman92@gmail.com)
