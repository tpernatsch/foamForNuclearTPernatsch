38 Class
39  Foam::powerModels::lumpedNuclearStructure
40 
41 Description
42  Model for representing a lumped-parameter structure characterized
43  by a user selectable number of nodes (indicated below as T[idx]).
44  \verbatim
45  Tmax T[0] T[1] T[n-1] Tsurface
46  | --- H[0] --- | --- H[1] --- | --- H[2] --- | --- H[n] --- |
47  \endverbatim
48  Note that only T[idx] are state variables while Tmax and Tsurface can
49  be found after matrix solution.
50  Note also that one needs n+1 conductances when solving for n nodes
51  The equation in the class can be obtained starting from a simple
52  energy balance for the ith node:
53 
54  $$
55  V_i \rho_i c_{p,i} \frac{dT}{dt} =
56  V Q q_f + H_i (T_{i-1} - T_i) - H_{i+1}(T_i - T_{i+1})
57  $$
58 
59  and dividing all terms by the volume of the structure.
60  This means that the heat conductances should be calculated as
61  the power flowing between two nodes divided by the diffence in
62  temperatures at steadystate, abd divided by the volume of the
63  structure.
64  Note that Q is the power density from neutronincs, which is
65  assumed to spead over all structure. The power fraction qf
66  can be used to concentrate this power over certain nodes.
67  Zero-gradient BCs are used at the inner boundary and convective
68  BCs are used at the external boundary (in contact with the coolant)
69 
70 Usage
71  The following sub-dictionary should be included as a powerModel
72  in phaseProperties.
73 
74  Example for one node:
75  \verbatim
76  powerModel
77  {
78  type lumpedNuclearStructure;
79  volumetricArea 40;
80  powerDensity 5e6; // Power density smeared over the entire
81  // structure
82  nodesNumber 1; // Number of nodes
83  nodeFuel 0; // Define which node temperature is used
84  // to parametrize XS according to
85  // nuclearDataFuelTemp
86  nodeClad 0; // Define which node temperature is used
87  // to parametrize XS according to
88  // nuclearDataCladExp. Of course, it does
89  // not have to represent a cladding. It
90  // could be used to parametrize over the
91  // graphite temperature in PBRs
92  nodeMatrix 0; // optional: Define which node temperature
93  // is used to perform a thermal diffusion
94  // in the matrix
95  kappaMatrix 10; // optional: Thermal conductivity in the
96  // matrix to compute the thermal diffusion.
97  // When set to 0, the thermal diffusion is
98  // not computed.
99  heatConductances (450000 225000); // Heat conductances from
100  // average to max,
101  // and average to surface.
102  // Note that heat conductances (W/K)
103  // must be divided by the volume
104  // of the entire structure.
105  // There must be one more conductance
106  // than the number of nodes
107  // (see explanation in class)
108  rhoCp (53576.92); // for each node
109  volumeFractions (1); // Fraction of the volume of the structure
110  // occupied by each node
111  powerFractions (1); // Fraction of total power in the strucure
112  // that goes to each node
113  T0 900; // Initial temperature, if no found in
114  // the time folder
115  }
116  \endverbatim
117 
118  Example for 3 nodes:
119  \verbatim
120  powerModel
121  {
122  type lumpedNuclearStructure;
123  volumetricArea 40;
124  powerDensity 5e6;
125  nodesNumber 3;
126  nodeFuel 0;
127  nodeClad 1;
128  nodeMatrix 2;
129  kappaMatrix 12;
130  heatConductances (600000 240000 600000 1200000);
131  rhoCp (53576.92 53576.92 53576.92);
132  volumeFractions (0.75 0.125 0.125);
133  powerFractions (1 0 0);
134  T0 900;
135  }
136  \endverbatim
