Detailed Description

Heat sink boundary for solid temperature defined by radiative and convective heat transfer coefficients.

Usage
cladOuter
{
    type            radiativeConvectiveSink;
    T0              uniform 600;
    alpha           uniform 50000;
    emissivity      uniform 0.5;
    value           $internalField;
}
