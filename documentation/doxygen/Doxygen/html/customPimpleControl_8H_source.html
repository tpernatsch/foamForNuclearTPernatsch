38 Class
39  Foam::customPimpleControl
40 
41 Description
42  PIMPLE control class to supply convergence information/checks for
43  the PIMPLE loop. In addition to standard PIMPLE functions, this class
44  adds support for a variable number of PISO iterations (via the
45  corrPISOUntilConvergence_ flag) within each PIMPLE iteration, and
46  adds an optional residual control for the number of PIMPLE iterations
47  performed in each time step based on the evaulation of the initialResidual
48  of the first PISO iteration in every PIMPLE iteration (rather than the
49  latest available initialResidual, from any PISO iteration, as done by the
50  base class). This proves particularly more useful for multiphase
51  simulation.
52 
53  Author:
54  Stefan Radman (stefan.radman@epfl.ch; stefanradman92@gmail.com)
55 
56 Usage
57  \verbatim
58  PIMPLE
59  {
60  nOuterCorrectors 12;
61  nCorrectors 8;
62  nNonOrthogonalCorrectors 0;
63  corrPISOUntilConvergence true; //- (new entry, default: false)
64 
65  residualControl
66  {
67  p_rgh
68  {
69  tolerance 5e-4;
70  relTol 0;
71  useFirstPISOInitialResidual true; //- (new entry, default: false)
72  }
73  }
74  }
75  \endverbatim
