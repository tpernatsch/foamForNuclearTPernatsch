27 Description
28  OFFBEAT (OpenFOAM Fuel BEhavior Analysis Tool) is a multi-dimensional fuel
29  performance code based on the open-source C++ library OpenFOAM. It can be
30  used both for the analysis of standard 1.5D cases and for more complex 2D
31  and 3D local effects.
