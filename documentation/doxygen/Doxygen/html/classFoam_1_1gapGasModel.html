Detailed Description

Parent class for gap gas model. The user can select the gap gas model specifying the keyword "gapGas" in the solver dictionary (solverDict).

The parent class typeName is "none". If selected in the solverDict the gap gas is not considered (e.g. for non-nuclear simulations or for verication tests).

The class derives from regIOobject. It writes/reads a file named "gapGas" at each time step.

Usage
In solverDict file: 
gapGas none;
