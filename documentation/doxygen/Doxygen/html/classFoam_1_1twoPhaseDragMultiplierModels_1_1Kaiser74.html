Detailed Description

Model by Kaiser et al. for the multiplier, specifically for sodium two-phase flows:

phi = 8.2/(X^0.55)

X2 is the well-known Lockhart-Martinelli parameter defined as:

X2 = (mu_I/mu_O)^0.2 * (flowQuality_I/flowQuality_O)^1.8 * rho_O/rho_I

Please note that X in use in phi is X = sqrt(X2) and that phi2 = phi^2

Kaiser, A., Peppler, W., Vöröss, L., 1974. "Type of flow, pressure drop, and critical heat flux of a two-phase sodium flow". Nucl. Eng. Des. 30, pp. 305–315.

Author: Stefan Radman (sradm.nosp@m.an@p.nosp@m.roton.nosp@m.mail.nosp@m..com / stefa.nosp@m.n.ra.nosp@m.dman@.nosp@m.epfl.nosp@m..ch)
