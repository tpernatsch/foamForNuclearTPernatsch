183  //- Feature that removes velocity oscillations and/or smearing in the
184  // main flow direction. However, if dealing with structures that have
185  // large porosity gradiens (i.e. > 0.5 between consecutive cells) or
186  // large gradients in the structure drag tensor, this feature may
187  // actually induce velocity oscillations in the directions
188  // perpendicular to the main flow direction (nedless to say, not in
189  // 1D). Only applicable to the face-momentum based algorithm.
190  // This factor weights the "traditional" faceMomentum velocity
191  // reconstruction (the one which always causes smearing/oscillations)
192  // in the main flow direction) with a moving phase fraction-adjusted
193  // velocity reconstruction (which may induced the aforementioned
194  // transversal oscillations). If set to 0, it is a pure "traditional"
195  // faceMomentum.
