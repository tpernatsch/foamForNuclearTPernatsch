24 Class
25  Foam::implicitGapContactFvPatchVectorField
26 
27 Description
28  Frictional contact boundary condition, similar to implicit contact.
29 
30  The normal contact component of the stress is discretized implicitly.
31  A blending coefficient is used to transition smoothly between the two conditions
32  of open and closed gap.
33 
34  The tangent traction is always treated explicitly (as in a fixed gradient BC).
35  However the details of the implementation change when moving from open gap
36  conditiosn (zero tangent traction) to full contact. In particular, in the
37  latter condition, the tangent component of the gradient is added implicitly
38  (see gradientBoundaryCoeff and gradientInternalCoeff functions), and subtracted
39  explicitly (see explicitTraction in the source code). This helps convergence.
40 
41  The user can select the amount of friction allowed with the frictionCoefficient.
42  If large enough, the material will tend to bond when in contact.
43  However, note that the full bonding traction is applied only when the
44  blending coefficient approaches 1 (and the frictionCoefficient is infinite).
45 
46  If glued is set to true, the material are assumed to be bonded (blending
47  coefficient is 1).
48 
49 Usage
50  \verbatim
51  "fuelOuter|claddingInner"
52  {
53  type implicitGapContact;
54  patchType regionCoupledOFFBEAT;
55 
56  // "off" by default. If "on" th patches are assumed
57  // to be glued to each other
58  glued off;
59 
60  // A new method of handling contact force can be activated using the 'augmentedLagrangian' method.
61  // By default, the method is set to 'implicitPenalty'.
62  // When using 'augmentedLagrangian', you can also set the relativePenetration tolerance.
63  // This tolerance defines the fraction of cell depth (delta) at which the penetration is considered acceptable.
64 
65  // method augmentedLagrangian;
66  // relativePenetrationTolerance 0.001;
67 
68  // Similar to penalty factor in explicit BC, the higher
69  // it is the more accurate the contact overlap, but more
70  // complex the convergence
71  penaltyFactor 0.1;
72  penaltyFactorFriction 0.001;
73  penaltyFactorDashpot 0.0;
74 
75  frictionCoefficient 0;
76 
77  relax 0.1;
78 
79  traction uniform (0 0 0);
80  pressure uniform 2.25e6;
81  value $internalField;
82  }
83  \endverbatim
