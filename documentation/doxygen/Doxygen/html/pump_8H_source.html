41 Description
42  Allow defining a momentum source, including options for a time
43  dependent source, and a source coming from an FMU
44 
45  Authors:
46  Stefan Radman (stefan.radman@epfl.ch / stefanradman92@gmail.com),
47  Carlo Fiorina for the FMU part
48 
49 Usage
50  Example of mandatory dictionary entries:
51  \verbatim
52  volumeFraction 0.5;
53  Dh 1;
54  momentumSource (0 0 1000);
55  \endverbatim
56 
57  Example of time dependant momentum source scaling entries:
58  \verbatim
59  momentumSourceTimeProfile
60  {
61  type table;
62  startTime 100;
63  table table
64  (
65  //- <Time> <Momentum source scaling factor>
66  ( 0 1 )
67  ( 1 0.1 )
68  );
69  }
70  \endverbatim
71 
72  Example of entries for scaling source coming from FMUs:
73  \verbatim
74  pumpMultiplierNameFromFMU momentumSourceCoupled;
75  \endverbatim
