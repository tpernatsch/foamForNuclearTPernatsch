25  Foam::rheology
26 
27 Description
28  Parent class that handles the evolution of rheological models.
29 
30  It handles the specific constitutive laws, e.g. elasticity, plasticity etc.
31  by modifying the stress tensor field.
32 
33  The parent class is not runTime selectable.
34 
35  For more information see [here](rheology.html).
