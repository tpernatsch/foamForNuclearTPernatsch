27 Description
28  This application is intended to be used for the coupling with the
29  TRANSURANUS 1.5D fuel performance code. It simply reads TU fields from a
30  dictionary located in "$FOAM_CASE/system/TuOFFBEATdict" and creates OFFBEAT
31  fields performing due interpolations on the OFFBEAT mesh.
