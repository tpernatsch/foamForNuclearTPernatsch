Passing "true" to fluid_.rho() returns the rho calculated according to the Boussinesq thermophysical model IF the Boussinesq equationOfState is being used. In fact, not passing anything to fluid_.rho() return the constant rho0 as a field (which is the rho ref called in UEqns.H).
