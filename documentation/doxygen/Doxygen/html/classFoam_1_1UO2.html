Detailed Description

UO2 material class.

The thermomechanical properties are taken from different sources, as BISON manual, FRAPCON manual or RELAP manual.

The material property and behavioral models can selected with the specific keywords. Otherwise, default models will be used.

Usage
In solverDict file: 
materials
{
    //! Name of cellZone with UO2 material model
    fuel
    {
        material UO2;

        densityModel            UO2Constant;
        heatCapacityModel       UO2MATPRO;
        conductivityModel       UO2MATPRO;
        emissivityModel         UO2RELAP;
        YoungModulusModel       UO2MATPRO;
        PoissonRatioModel       UO2Constant;
        thermalExpansionModel   UO2RELAP;

        densificationModel      UO2FRAPCON;
        swellingModel           UO2FRAPCON;
        relocationModel         UO2FRAPCON;
        failureModel            none;
    }

    ...

}
