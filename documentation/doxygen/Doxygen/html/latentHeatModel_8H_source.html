94  // Adjust the latent heat of vaporization in a manner consistent
95  // with how massTransfer-related enthalpy is added to the energy
96  // equations. In particular:
97  // * when evaporating, mass is removed from the liquid at its current
98  // enthalpy and is added to the vapour at vapour saturation
99  // entalphy;
100  // * when condensing, mass is removed from the vapour at its current
101  // enthalpy and is added to the liquid at liquid saturation
102  // enthalpy.
103  // For example, in the case of condensing super-heated steam, its
104  // enthalpy will be larger than saturation enthalpy. However, if
105  // you remove mass from the steam at an enthalpy lower than its
106  // current enthalpy, the remaining steam will inevitably be
107  // hotter.
108  // Thus:
109  // * when evaporating, the latent heat will be decreased by the difference
110  // between the current liquid enthalpy and the saturation liquid
111  // enthalpy;
112  // * when condensing, the latent heat will be increased by the difference
113  // between the current vapour enthalpy and the saturation vapour
114  // enthalpy.
115  const bool adjust_;
116 
117  //- L > 0 if fluid1_ is liquid and fluid2_ is vapour, < 0 if vice-versa.
118  // This comes from the fact that the rest of the code is hard-coded so
119  // that dmdt represents a mass transfer from fluid1 to fluid2 if positive,
120  // the opposite when negative
121  const int LSign_;
