Detailed Description

Base class for handling corrosion models. The user can select the corrosion model specifying the keyword "corrosion" in the solver dictionary (solverDict).

The parent class typeName is "fromLatestTime". If selected in the solverDict the corrosion does not evolve. However, the two corrosion fields ('oxideThickness' and 'DOxideThickness') are created, added to the registry and written at the end of the time step.

If the files are present in the starting time folder, the internal field and boundary conditions are set according to the file.

Otherwise, the fields are set to 0 m in each cell, with zeroGradient BCs in all non-empty/-wedge patches.

Usage
In solverDict file: 
corrosion fromLatestTime;

corrosionOptions
{
    // The updateMesh switch is set to true by default
    updateMesh     true;
}
