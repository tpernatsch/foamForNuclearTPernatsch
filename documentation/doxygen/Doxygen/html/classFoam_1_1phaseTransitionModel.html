Detailed Description

Parent class for phase transition model.

The parent class typeName is "none". If selected in the solverDict the phase change is not considered, but the field 'betaFraction' is created and added to registry.

If the 'betaFraction' file is present in the starting time folder, the internal field and boundary conditions are set according to the file.

Otherwise, the field is set to 0 in each cell, with zeroGradient BCs in all non-empty/-wedge patches.

Usage
In solverDict file: 
materials
{
    ...

    cladding
    {
        material zircaloy;

        ...

        phaseTransitionModel     none;
    }

    ...
}
