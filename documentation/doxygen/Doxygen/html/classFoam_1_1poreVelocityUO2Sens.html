Detailed Description

Model to compute pore velocity with the correlation provided by Sens (P.F. Sens. The kinetics of pore movement in UO2 fuel rods. Journal of Nuclear Materials, 43(3):293–307, 1972. doi:10.1016/0022-3115(72)90061-X.).

In addition, a correction factor can be defined to correct the velocity (default value is 1.0).

Usage
In solverDict file: 
materials
{
    fuel
    {
        material UPuO2;

        ...

        poreVelocityModel     UO2Sens;
        // Multiplicator for pore velocity
        // alphaPoreVelocity 1;
    }

    ...
}
