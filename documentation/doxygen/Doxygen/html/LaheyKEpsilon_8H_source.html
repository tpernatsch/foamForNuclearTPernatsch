44 Description
45  Continuous-phase k-epsilon model including bubble-generated turbulence.
46 
47  Reference:
48  \verbatim
49  Lahey Jr, R. T. (2005).
50  The simulation of multidimensional multiphase flows.
51  Nuclear Engineering and Design, 235(10), 1043-1060.
52  \endverbatim
53 
54  The default model coefficients are
55  \verbatim
56  LaheyKEpsilonCoeffs
57  {
58  Cmu 0.09;
59  C1 1.44;
60  C2 1.92;
61  C3 -0.33;
62  sigmak 1.0;
63  sigmaEps 1.3;
64  Cp 0.25;
65  Cmub 0.6;
66  alphaInversion 0.3;
67  }
68  \endverbatim
69 
70  Last modified by Stefan Radman for compatibility with FFSEulerFoam
71  (stefan.radman@epfl.ch, stefanradman92@gmail.com)
72 
73 SourceFiles
74  LaheyKEpsilon.C
75 
76 Note
77  This model will work as expected only in scenarios where the gas is
78  dispersed and the liquid is continuous! While it will still technically
79  run also in opposite scenarios, the validity of the results is
80  questionable. This is due to the fact that the fluid-fluid drag coefficient
81  Cd is computed by taking into consideration the dispersed Dh and continuous
82  rho, while the source terms in this model are hard-coded to use the
83  gas Dh and liquid rho in the different terms. Why? Read the paper from
84  Lahey, this model was devised only for these dipsersed gas / continuous
85  liquid scenarios
