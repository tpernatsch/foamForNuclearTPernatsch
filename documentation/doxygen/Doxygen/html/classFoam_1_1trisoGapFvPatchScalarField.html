Detailed Description

Region coupled patchField for temperature fields in solid heat conduction in a spherical gap.

Usage
  bufferOuter
{
  type            trisoGap;
  patchType       regionCoupledOFFBEAT;
  kappa           k;
  coupled         true;
  roughness       uniform 1e-6;
  jumpDistance    uniform 0.0;
  value           $internalField;
  relax           1;
}

ipycInner
{
  type            trisoGap;
  patchType       regionCoupledOFFBEAT;
  kappa           k;
  coupled         true;
  roughness       uniform 1e-6;
  jumpDistance    uniform 0.0;
  value           $internalField;
  relax           1;
}
