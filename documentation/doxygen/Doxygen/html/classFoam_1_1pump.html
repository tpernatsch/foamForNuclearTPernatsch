Detailed Description

Allow defining a momentum source, including options for a time dependent source, and a source coming from an FMU.

Authors: Stefan Radman (stefa.nosp@m.n.ra.nosp@m.dman@.nosp@m.epfl.nosp@m..ch / stefa.nosp@m.nrad.nosp@m.man92.nosp@m.@gma.nosp@m.il.co.nosp@m.m), Carlo Fiorina for the FMU part

Usage
Example of mandatory dictionary entries: 
    volumeFraction      0.5;
    Dh                  1;
    momentumSource      (0 0 1000);

Example of time dependant momentum source scaling entries: 

    momentumSourceTimeProfile
    {
        type        table;
        startTime   100;
        table       table
        (
            //! <Time>  <Momentum source scaling factor>
            (   0       1   )
            (   1       0.1 )
        );
    }

Example of entries for scaling source coming from FMUs: 

    pumpMultiplierNameFromFMU   momentumSourceCoupled;
