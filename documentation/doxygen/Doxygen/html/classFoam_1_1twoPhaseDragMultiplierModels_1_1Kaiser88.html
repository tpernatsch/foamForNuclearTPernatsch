Detailed Description

Model by Kaiser et al. for the multiplier, specifically for sodium two-phase flows:

phi2 = exp(2*( 1.48 - 1.05*log(sqrt(X)) + 0.09*(log(sqrt(X)))^2 ))

log is the natural logarithm and X2 is the well-known Lockhart-Martinelli parameter defined as:

X2 = (mu_I/mu_O)^0.2 * (flowQuality_I/flowQuality_O)^1.8 * rho_O/rho_I

Please note that X in use in phi2 is X = sqrt(X2).

Kaiser, A., Huber, F., Bottoni, M., Dorr, B., 1988. "Contribution to sodium boiling heat transfer, pressure drop, and void distribution in multi-pin geometry". In: Proc. 13th Liquid Metal Boiling Working Group (LMBWG), pp. 71–98.

Author: Stefan Radman (sradm.nosp@m.an@p.nosp@m.roton.nosp@m.mail.nosp@m..com / stefa.nosp@m.n.ra.nosp@m.dman@.nosp@m.epfl.nosp@m..ch)
