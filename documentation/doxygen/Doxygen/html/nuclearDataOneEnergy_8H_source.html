39  Foam::nuclearDataOneEnergy
40 
41 Description
42  Subclass for nuclear data handling. The interpolation scheme used is based
43  on the polyharmonic spline radial basis function (RBF). The RBF used is
44  linear. This class is able to interpolate any number of perturbed states for
45  any number of parameters.
46 
47 \f[
48  \sigma_{E_g, \Omega_l}(\textbf{x})
49  = \sum_{i=1}^{N_{perturb}} w_i \phi(\|\textbf{x} - \textbf{c}_i\|)
50  + v_0
51  + \sum_{k=1}^{N_{param}} v_k x_k
52 \f]
53 
54 \vartable
55  \textbf{x} | Parameter vector of size \f$ N_{param} \f$: \f$ \{ T_{fuel}, T_{clad}, T_{cool}, T_{struct}, \rho_{cool}, \alpha_{axial}, \alpha_{radial} \} \f$
56  \textbf{c}_i | \f$ N_{perturb} \f$ data points to interpolate, each data point is of size \f$ N_{param} \f$
57  \textbf{w} | Weights of the RBF of size \f$ N_{perturb} \f$
58  \textbf{v} | Polynomial weights of size \f$ N_{param} \f$
59 \endvartable
60 
61 The basis function form used is linear
62 \f[
63  \phi(\| \textbf{x} - \textbf{c}_i \|) = \| \textbf{x} - \textbf{c}_i \| \quad
64  (\phi(r) = | r |)
65 \f]
66 
67 The weights \f$ w_i \f$ and \f$ v_j \f$ are determined such that the function
68 interpolates \f$ N_{perturb} \f$ given points \f$ (\textbf{c}_i, \sigma_{i}) \f$
69 (for i = 1, 2, …, \f$ N_{perturb} \f$) and fulfills the \f$ N_{param} + 1 \f$
70 orthogonality conditions
71 \f[
72  \sum_{i=1}^{N} w_{i} = 0 \quad \quad
73  \sum_{i=1}^{N} w_{i} \textbf{c}_{i} = \textbf{0}
74 \f]
75 
76 All together, these constraints are equivalent to the symmetric linear system of equations
77 \f[
78 
79  \begin{bmatrix} A & B \\ B^{\textrm {T}} & 0 \end{bmatrix}
80  \begin{bmatrix} \textbf{w} \\ \textbf{v} \end{bmatrix}
81  =
82  \begin{bmatrix} \sigma \\ \textbf{0} \end{bmatrix}
83 \f]
84 
85 where
86 \f[
87  A_{i,j} = \phi(|\textbf{c}_i - \textbf{c}_j|)
88  \quad \quad
89  B = \begin{bmatrix}
90  1 & 1 & \cdots & 1 \\
91  \textbf{c}_1 & \textbf{c}_2 & \cdots & \textbf{c}_N
92  \end{bmatrix}^{\textrm {T}}
93  \quad \quad
94  \sigma = \left[ \sigma_1, \sigma_2, \ldots, \sigma_N \right]^{\textrm {T}}
95 \f]
