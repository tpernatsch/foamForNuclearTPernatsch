User documentation for PuRedistribution solver

For general instructions on the modeling of element transport in OFFBEAT see here.

The PuRedistribution transport solver solves for the migration of Plutonium in MOX fuel pellets.

Formulation

The redistribution process takes place due to two concurrent phenomena: thermal diffusion (i.e. Soret diffusion) and vapor transport, that are modelled through the following PDE:

$$ \begin{aligned} \frac{\partial c}{\partial t} + \nabla \cdot \left\{\left[\nabla c + c(1-c)\frac{Q}{R\cdot T^2}\nabla T\right] - D\left[\frac{APcl}{d}\nabla T \cdot exp{\left(-\frac{D}{lv_p}\right)} \right]\right\} = 0 \end{aligned} $$

where:

  • \( c \) is the Pu concentration,
  • \( Q \) is the effective molar heat of transport,
  • \( R \) is the universal gas constant,
  • \( T \) is the temperature,
  • \( A \) is a model parameter,
  • \( P \) is the porosity,
  • \( v_p \) is the pore velocity,
  • \( D \) is the diffusion coefficient,
  • \( l \) is the pores' thickness,
  • \( d \) is the pores' diameter.

The diffusion coefficient for Pu is calculated as: $$ \begin{aligned} D_{Pu} = 3.4\cdot10^{-5}exp{\left(\frac{-55891}{T}\right)} \end{aligned} $$

The pore migration contribution can be switched off with a dedicated keyword (see Usage below).

Usage

To use the PuRedistribution solver in OFFBEAT, the user will need to specify it in the solverDict dictionary using the following syntax:


    elementTransport byList;

    elementTransportOptions
    {
        solvers ( AmRedistribution );

        AmRedistributionOptions
        {
            poreMigration off;
        }
    }
