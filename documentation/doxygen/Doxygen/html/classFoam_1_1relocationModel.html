Detailed Description

Parent class for relocation model.

The parent class typeName is "none". If selected in the solverDict the relocation is not considered, but the relocation fields 'epsilonRelocation' and 'epsilonRecoveredRelocation' are created and ad0ded to registry.

If the files are present in the starting time folder, the internal field and boundary conditions are set according to the file.

Otherwise, the fields are set to 0 in each cell, with zeroGradient BCs in all non-empty/-wedge patches.

Usage
In solverDict file: 
materials
{
    fuel
    {
        material UO2;

        ...

        relocationModel     none;
    }

    ...
}
