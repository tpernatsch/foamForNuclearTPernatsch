24 Class
25  Foam::largeStrainTotLag
26 
27 Description
28  Finite- (or large-) strain mechanics sub-solver.
29 
30  It solves for total displacement 'D' in a total Lagrangian configuration
31  (i.e. the mesh is not updated).
32 
33  The geometric non-linearity (i.e. the inter-dependence between displacement
34  and geometric configuration) is taken care of by multiplying the stress
35  tensor (Cauchy) by J*F.inv(), where F is the deformation gradient and J is
36  the determinant of F.
37 
38  By default, the strain tensor takes into account the second order deformations:
39  \f[
40  epsilon = E = 0.5*(gradD + gradD.T() + gradD*gradD.T())
41  \f]
42 
43  However, with the "linearStrainTensor" keyword, the user can decide to force
44  a linear strain tensor:
45  \f[
46  epsilon = 0.5*(gradD + gradD.T())
47  \f]
48 
49 
50 Usage
51  In solverDict file:
52  \verbatim
53  mechanicsSolver largeStrainTotLag;
54 
55  mechanicsOptions
56  {
57  // Print summary of boundary-forces at each iteration
58  forceSummary false;
59 
60  // Force linear strain tensor
61  linearStrainTensor false;
62 
63  // Creates cylindrical stress and displacement field (for debugging)
64  cylindricalStress false;
65 
66  // Apply RhieChowCorrection to stabilize momentum equation (it should
67  // be activated in most situations)
68  RhieChowCorrection true;
69 
70  // Additional subDict for multi-material cases
71  multiMaterialCorrection
72  {
73  ...
74  }
75 
76  }
77  \endverbatim
