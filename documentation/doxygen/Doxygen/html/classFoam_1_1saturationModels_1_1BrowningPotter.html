Detailed Description

Saturation model based on results by Browning and Potter, refer to https://www.ne.anl.gov/eda/ANL-RE-95-2.pdf. The saturation pressure form is lnPSat = A + B/TSat + C*ln(TSat), which is not invertible in TSat. TSat is inverted by approximateding ln(TSat) by a second order polyinomial.
