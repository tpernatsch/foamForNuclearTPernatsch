24 Class
25  Foam::materials
26 
27 Description
28  Parent class that handles the evolution of material properties and
29  behavioral models.
30 
31  The material models are stored in a PtrList. The addressing of each material
32  is stored in a labelListList.
33 
34  The mother class is not runtime-selectable.
