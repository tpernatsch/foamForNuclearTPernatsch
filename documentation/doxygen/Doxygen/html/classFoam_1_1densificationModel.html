Detailed Description

Parent class for densification model.

The parent class typeName is "none". If selected in the solverDict the densification is not considered, but the densification field 'epsilonDensification' is created and added to registry.

If the 'epsilonDensification' file is present in the starting time folder, the internal field and boundary conditions are set according to the file.

Otherwise, the field is set to 0 in each cell, with zeroGradient BCs in all non-empty/-wedge patches.

Usage
In solverDict file: 
materials
{
    fuel
    {
        material UO2;

        ...

        densificationModel     none;
    }

    ...
}
