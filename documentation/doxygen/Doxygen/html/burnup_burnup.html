User documentation for none burnup class

For general instructions on the modeling of burnup in OFFBEAT see here.

As the name implies, the none burnup class in OFFBEAT allows you to switch off the burnup model and have a simulation where burnup is not considered. This means that the burnup field Bu is not created.

Note
The abscence of the Bu field might create conflicts with other models that partially or entirely depends on the burnup (e.g. fuel conductivity).
If you want to use those models bust still neglect the burnup evolution, use the fromLatestTime model.

Usage

To use the none burnup model in OFFBEAT, the user needs to specify it in the solverDict dictionary using the following syntax:


    burnup none;
