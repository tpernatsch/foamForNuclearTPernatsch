Detailed Description

template<class FieldType, class Type, class ReturnType>
class Foam::InterpolateTableGF< FieldType, Type, ReturnType >

Class for interpolation in tabulated data. This class doesn't actually store any fields, but is intended as a quick helper class to perform the actual interpolation for different data types, i.e. Fields, FieldFields, etc. effectively facilitating multi-dimensional interpolation. Currently provides two interpolation methods, step and linear (see )

This is an alternative to OpenFOAM's built in InterpolateTableGF and interpolateTable2D classes, which partially combines the two using templates. It was created largely for 2D tables where we want to look up one dimension first and then interpolate many times in the resulting data, i.e. create a 1D table by interpolating in a 2D table.
