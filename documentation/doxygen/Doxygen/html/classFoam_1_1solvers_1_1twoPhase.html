This is specifically to avoid problem when solveAlpha is set to solve

for only one phase, the one for which BCs and initial conditions are provided, yet this phase starts at 0 while the other phase BC and initial conditions were not provided. This is problematic as by default a phase defaults to 0, so if the provided phase is 0 everywhere too, you have issues with the normalization later. This is veeeery specific but hey, why not!
