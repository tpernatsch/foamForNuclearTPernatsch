169  //- Feature that removes velocity oscillations and/or smearing in the
170  // main flow direction. However, if dealing with structures that have
171  // large porosity gradiens (i.e. > 0.5 between consecutive cells) or
172  // large gradients in the structure drag tensor, this feature may
173  // actually induce velocity oscillations in the directions
174  // perpendicular to the main flow direction.
175  // This factor weights the "traditional" faceMomentum velocity
176  // reconstruction (the one which always causes smearing/oscillations)
177  // in the main flow direction) with a moving phase fraction-adjusted
178  // velocity reconstruction (which may induced the aforementioned
179  // transversal oscillations). This feature only has an affect on the
180  // cellCentered and the cellCenteredFaceReconstruction momentum modes.
181  // Deafults to 0, which amounts to a "traditional" velocity reconstruction
182  // procedure from phi
183  const scalar porousInterfaceSharpness_;
