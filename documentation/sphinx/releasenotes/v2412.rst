===================
What's New in v2412
===================

.. currentmodule:: foamForNuclear

In 2024 a very large restructuring of GeN-Foam has taken place. This has led
to many modifications to different dictionaries. While we are aware that these
changes can make the input deck more complicated, the new features offer very
large advantages in terms of code flexibility. Examples of these will be
presented in future publications.

In point-kinetics neutronics sub-solver, the parameter `feedbackCoeffFastDoppler`
in `constant/nuclearData` has been changed to `feedbackCoeffDoppler`, which is
more generic. One can select the spectrum type using `fastNeutrons`. Thus the
sqrt law or the log law will be applied.

Addition of XS variable selection with the `xsVariables` dictionary in
`constant/neutroRegion/nuclearData`. This subdict is mandatory even if the XS
are not perturbed, it can be assign empty (`xsVariables {};`).
