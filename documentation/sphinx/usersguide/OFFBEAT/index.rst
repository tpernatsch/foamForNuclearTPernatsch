OFFBEAT
====================

The OpenFOAM Fuel BEhavior Analysis Tool (OFFBEAT) is a multi-dimensional
(1D, 2D, 3D) finite-volume nuclear fuel performance code based on the
`OpenFOAM® C++ library <https://openfoam.com/>`_.

OFFBEAT is developed as part of the
`foamForNuclear <https://gitlab.com/foamForNuclear/foamForNuclear>`_
framework, which aims at providing a comprehensive multi-physics simulation
environment for nuclear engineering applications.

OFFBEAT is mainly developed at the
`Laboratory of Reactor Safety (LRS) <https://www.epfl.ch/labs/lrs>`_
at École Polytechnique Fédérale de Lausanne (EPFL), the
`Laboratory for Reactor Physics and Thermal-Hydraulics (LRT) <https://www.psi.ch/en/lrt>`_
at the Paul Scherrer Institut (PSI), and the
`Modeling, Engineering, Design and Analysis Laboratory (MEDAL) <https://medal.engr.tamu.edu/>`_
at Texas A&M University.

The project also benefits from a growing number of contributions from other
academic and research institutions.
