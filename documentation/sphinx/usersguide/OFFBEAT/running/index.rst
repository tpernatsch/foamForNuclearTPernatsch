Running OFFBEAT
===============

This section describes how to set up and run OFFBEAT to perform fuel
behaviour simulations.

The usage instructions provided here assume that the user has a basic
understanding of OpenFOAM, including the standard workflow
(mesh generation, preprocessing, solver execution, and post-processing),
as well as familiarity with the OpenFOAM dictionary format.

.. warning::

   New users are strongly encouraged to first work through the
   `OpenFOAM v9 User Guide <https://cfd.direct/openfoam/user-guide/>`_
   from the OpenFOAM Foundation, or the equivalent
   `OpenFOAM v2312 User Guide <https://doc.openfoam.com/2312/>`_
   from the ESI Group, before attempting to use OFFBEAT.
