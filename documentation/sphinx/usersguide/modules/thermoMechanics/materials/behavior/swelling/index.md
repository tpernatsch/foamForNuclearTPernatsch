# <b>Swelling</b>

Swelling models describe volumetric changes induced by irradiation, temperature
or microstructural evolution.

The swelling model is selected with the
<code><b>swellingModel</b></code> keyword inside the material subdictionary
of the <code><b>solverDict</b></code>.

## <b>Classes</b>

Currently, OFFBEAT supports the following swelling models:

- [none](../../../../classes/materials/materialModel/behavioralModels/swelling/swellingModel.md)  
  neglects swelling effects.

- [constantRate](../../../../classes/materials/materialModel/behavioralModels/swelling/constantSwelling.md)  
  constant swelling rate model.

- [UO2Frapcon](../../../../classes/materials/materialModel/behavioralModels/swelling/swellingFrapcon.md)  
  FRAPCON-based swelling model for UO₂ fuel.

- [UO2Matpro](../../../../classes/materials/materialModel/behavioralModels/swelling/swellingMatpro.md)  
  MATPRO-based swelling model for UO₂ fuel.

- [UPuO2Fbr](../../../../classes/materials/materialModel/behavioralModels/swelling/swellingFBRMOX.md)  
  FBR-based swelling model for MOX fuel.

- [BufferParfume](../../../../classes/materials/materialModel/behavioralModels/swelling/swellingParfumeBuffer.md)  
  PARFUME-based swelling model for buffer layers.

- [PyCParfume](../../../../classes/materials/materialModel/behavioralModels/swelling/swellingParfumePyC.md)  
  PARFUME-based swelling model for PyC layers.

- [PyCCorrelation](../../../../classes/materials/materialModel/behavioralModels/swelling/swellingCorrelationPyC.md)  
  Empirical swelling correlation for PyC.

- [SiCParfume](../../../../classes/materials/materialModel/behavioralModels/swelling/swellingParfumeSiC.md)  
  PARFUME-based swelling model for SiC.

- [Steel1515TiAim1](../../../../classes/materials/materialModel/behavioralModels/swelling/swellingGrowthAIM11515Ti.md)  
  AIM1 swelling model for 15-15Ti steel.

- [Steel1515TiGeneralized](../../../../classes/materials/materialModel/behavioralModels/swelling/swellingGrowthGeneralized1515Ti.md)  
  Generalized swelling model for 15-15Ti steel.

- [FeCrAl](../../../../classes/materials/materialModel/behavioralModels/swelling/swellingFeCrAl.md)  
  Swelling model for FeCrAl alloys.

- [HastelloyNWrightSham](../../../../classes/materials/materialModel/behavioralModels/swelling/swellingWrightShamHastelloyN.md)  
  Wright–Sham swelling model for Hastelloy N.

- [ZircaloyBison](../../../../classes/materials/materialModel/behavioralModels/swelling/swellingGrowthBisonZircaloy.md)  
  BISON-based swelling model for Zircaloy.

- [ZircaloyMatpro](../../../../classes/materials/materialModel/behavioralModels/swelling/swellingGrowthMatproZircaloy.md)  
  MATPRO-based swelling model for Zircaloy.
