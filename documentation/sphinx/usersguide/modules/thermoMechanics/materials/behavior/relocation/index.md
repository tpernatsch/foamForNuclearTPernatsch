# <b>Relocation</b>

Relocation models describe the outward displacement of fuel
material, typically associated with cracking and fragmentation.

The relocation model is selected with the
<code><b>relocationModel</b></code> keyword inside the material subdictionary
of the <code><b>solverDict</b></code>.

## <b>Classes</b>

Currently, OFFBEAT supports the following relocation models:

- [none](../../../../classes/materials/materialModel/behavioralModels/relocation/relocationModel.md)  
  neglects relocation effects.

- [UO2Frapcon](../../../../classes/materials/materialModel/behavioralModels/relocation/relocationFrapcon.md)  
  FRAPCON-based relocation model for UO₂ fuel.
