# <b>Phase Transition</b>

Phase transition models describe changes in material phase induced by
temperature or transient conditions.

The phase transition model is selected with the
<code><b>phaseTransitionModel</b></code> keyword inside the material
subdictionary of the <code><b>solverDict</b></code>.

## <b>Classes</b>

Currently, OFFBEAT supports the following phase transition models:

- [none](../../../../classes/materials/materialModel/behavioralModels/phaseTransition/phaseTransitionModel.md)  
  neglects phase transition effects.

- [ZircaloyDynamic](../../../../classes/materials/materialModel/behavioralModels/phaseTransition/phaseTransitionZircaloyDynamic.md)  
  dynamic phase transition model for Zircaloy.
