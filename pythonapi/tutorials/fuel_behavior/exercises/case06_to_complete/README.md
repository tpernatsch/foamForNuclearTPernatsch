# Description

In Case 6, we complete our (simplified) thermo-mechanical analysis of a single fuel rod slice by adding two final missing critical components: the fission gas behavior and the swelling. Fission gas behavior is one of the most complicated aspects of fuel performance. In OFFBEAT, we incorporate SCIANTIX, a standalone 0D code developed at PoliMi, as our state-of-the-art fission gas behavior module. SCIANTIX treats the diffusion of gas atoms (generated by fission) in the fuel grains, and predicts the amount of gas dissolved in the grain or trapped in bubbles at grain boundaries. It includes also a grain boundary model that can predict the size of the grain boundary bubbles depending on the gas influx, fuel temperature and hydrostatic stress. Once saturation thresholds are reached, gases are partially released from the grain boundary bubbles, a phenomenon known as Fission Gas Release (fgr). This can have a significant impact on the gap pressure and gap conductance — notably, Xenon and Krypton have lower thermal conductivities compared to Helium. Additionally, the growth or shrinkage of intra- and intergranular bubbles determines the gaseous fuel swelling, the larger component of fuel swelling compared to solid swelling.

To take swelling into account in the mechanical strain–stress balance, this simulation also activates swelling models for both UO$_2$ fuel and the cladding. For the fuel, we use the **UO2Frapcon** model, which incorporates a burnup-dependent correlation for solid swelling and receives gaseous swelling from SCIANTIX. For the cladding, the default swelling correlation is used. Note that cladding swelling (often referred to as growth) is driven by fast neutron damage and manifests as axial elongation and radial thinning.

# Tasks

1. **Create the folder.**
   Either copy `case06/` in your working directory, or duplicate `case05/` and rename it to `case06`.
   Then clean the folder using:

   ```
   python3 clean.py
   ```

2. **Update `case06/case.py`.**
   Enable fission gas behavior and swelling:

   * **Activate fission gas release.**
     Enable the **SCIANTIX** fission gas release model and provide its input settings using a `SciantixDict`.
     The SCIANTIX options correspond to the `input_settings.txt` file used in legacy OFFBEAT cases
     or in stand-alone SCIANTIX run.

   * **Activate fuel swelling.**
     Enable a `swellingModel` for the fuel using **UO2Frapcon**, which combines solid swelling correlations with gaseous swelling from SCIANTIX.

   * **Activate cladding swelling.**
     Enable the default swelling model for Zircaloy.

   * **Extend the `fuelOuter` patch probe.**
     Add the following fields to the `fuelOuter` probe:

     * `interfaceP` (fuel–clad contact pressure)
     * `hGap` (gap conductance)

3. **Run OFFBEAT.**
   From the `case06` directory, run:

   ```
   python run.py
   ```

   or

   ```
   python3 run.py
   ```

4. **Post-process.**
   Plot the results with:

   ```
   python post.py
   ```

5. **Extract data for the MATLAB grader.**
   Extract:

   * `case/postProcessing/fuelCenterline/0/T`
   * `case/postProcessing/fuelOuter/0/gapWidth`
   * `case/postProcessing/fuelOuter/0/interfaceP`
   * `case/postProcessing/fuelOuter/0/hGap`

   using:

   ```
   python extractData.py
   ```

   or

   ```
   python3 extractData.py
   ```

6. **Copy the extracted data into the MATLAB grader.**
