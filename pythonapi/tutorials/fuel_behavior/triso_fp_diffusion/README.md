# TRISO FP Diffusion Benchmark Suite

Verification and validation cases for the OFFBEAT fission-product transport solver,
based on the IAEA CRP-6 benchmark for HTGR fuel. Each case
simulates Cs (and/or Ag) diffusion through a 1-D spherical TRISO fuel particle using
the foamForNuclear Python API.

The benchmark is organised into four groups of increasing complexity. Each group lives
in its own subdirectory and is self-contained: it has its own geometry and material data
(`_config.py`), case builder (`case.py`), runner (`run.py`), post-processor (`post.py`),
and cleaner (`clean.py`). Automated verification tests are collected at the root level
(`test_cases_*.py`) and run with pytest.

---

## Case groups

### `cases_1_2` — Constant-temperature heating (200 h)

**Physics:** Cs diffusion only. Initial imposed inventory, uniform in the kernel.
No irradiation; particle held at a single constant
temperature for 200 h (cases 1a/1b) or with a step change in temperature (cases 2a/2b).

| Case | Temperature history | Species |
|---|---|---|
| case_1a | Constant 1273 K | Cs |
| case_1b | Constant 1473 K | Cs |
| case_2a | Step 1273 → 1473 K at 100 h | Cs |
| case_2b | Step 1473 → 1273 K at 100 h | Cs |

**Verification:** final fractional release compared to IAEA reference values. Tests are
fast (no irradiation phase) and carry no `slow` marker.

---

### `cases_3` — Irradiation + constant-temperature heating (400 h)

**Physics:** Cs diffusion through full five-layer TRISO geometry. Cases cover a range of
burnup levels and heating temperatures.

**Verification:** final fractional release compared to IAEA reference values. Tests are
marked `@pytest.mark.slow` because they include an irradiation phase.

---

### `cases_4` — Irradiation + temperature-ramp heating (400 h)

**Physics:** Cs + Ag diffusion. Long irradiation phase (12 000 h) followed by a
400 h heating transient. Cases vary the heating temperature profile.

**Verification:** final fractional release for both Cs and Ag compared to IAEA reference
values. Tests are marked `@pytest.mark.slow`.

---

### `cases_5` — Cyclic irradiation + heating (24 000 h + 200 h)

**Physics:** Cs + Ag diffusion. 10 × 100 effective full-power-day (efpd) cyclic
irradiation followed by a 200 h post-irradiation heating test.

- **case_5a snapshot** — fractional release at end of irradiation (t = 24 000 h).
  IAEA reference has large participant spread; no assertion made.
- **case_5b** — fractional release at end of post-irradiation heating (200 h @ 1600 K).
  IAEA reference: Cs ≈ 6.5×10⁻⁴ (±80 %).

**Verification:** end-of-heating release compared to IAEA reference. Tests are
marked `@pytest.mark.slow`.

## Directory layout

```
triso_fp_diffusion/
├── conftest.py                # shared pytest fixtures and I/O helpers
├── test_cases_1_2.py          # automated tests for cases 1 & 2
├── test_cases_3.py            # automated tests for cases 3a–3e
├── test_cases_4.py            # automated tests for cases 4a–4d
├── test_cases_5.py            # automated tests for case 5b
├── clean.py                   # top-level clean: delegates to group cleaners
│
├── reference_figures/         # IAEA CRP-6 reference figures (committed)
│   ├── case_1_2_fractional_Cs_0h_200h_0_1.png
│   ├── case_3_fractional_Cs_0h_400h_1e-8_1_log.png
│   ├── case_4_fractional_Cs_0h_400h_1e-8_1_log.png
│   ├── case_5_fractional_Cs_0h_24000h_1e-8_1_log.png
│   └── case_5_fractional_Cs_0h_200h_1e-8_1_log.png
│
├── cases_1_2/
│   ├── _config.py             # geometry, materials, boundary conditions
│   ├── case.py                # builds the OpenFOAM case via the Python API
│   ├── run.py                 # runs one or more cases
│   ├── post.py                # plots simulation vs reference
│   ├── clean.py               # removes generated case directories and figures/
│   ├── case_1a/  case_1b/  case_2a/  case_2b/  # generated at runtime (not committed)
│   └── figures/               # generated at runtime (not committed)
│
├── cases_3/                   # same layout
├── cases_4/                   # same layout
└── cases_5/                   # same layout
```

Each `case_N/` subdirectory is an OpenFOAM case generated by `case.py`; it is not
committed to version control and is re-created by `run.py`.

---

## Reference figures

All reference figures are PNG images digitised from the IAEA CRP-6 benchmark report.
They live in the central `reference_figures/` directory and are committed to the
repository.

Each `post.py` overlays the OFFBEAT simulation result directly on the reference PNG
using `matplotlib.image.imread` and `imshow`, matching axes limits defined in the
`REFERENCE_FIGS` dict inside each `post.py`.

## Typical workflow

Run from inside the relevant case-group directory (all scripts use
`os.path.abspath(__file__)` so they work regardless of where Python is invoked from).

```bash
# 1. Build and run all cases in a group
cd cases_3
python run.py                  # all cases
python run.py case_3a          # single case

# 2. Post-process (saves overlay figures to figures/)
python post.py                 # all cases
python post.py case_3b case_3c # subset

# 3. Clean (remove generated OpenFOAM case directories)
python clean.py
```

## Running the test suite

From the `triso_fp_diffusion/` root:

```bash
# Fast tests only (cases 1 & 2)
pytest -v test_cases_1_2.py

# All tests
pytest -v

# Skip slow tests
pytest -v -m "not slow"

# Single case
pytest -v test_cases_5.py -k "case_5b"
```
