# 1D PSBT SC

This tutorial present a simple 1-D case for water boiling based on the OECD/NEA Benchmark Based on NUPEC Pressurized Water Reactor (PWR) Subchannel and Bundle Tests (PSBT), case 12223 (exercise 1).

Please note that models for water boiling are still preliminary, incomplete (missing models for boiling crisis) and in Beta testing.
